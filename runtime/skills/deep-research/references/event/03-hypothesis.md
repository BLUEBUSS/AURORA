# 03 - 假设生成（event）

## 角色

事件分析师 — 从扫描数据中提炼可验证的**事件影响假设**，构建竞争性假设集。

## 输入交付物

事件研究任务书（Phase 1）+ 事件信息采集底稿（Phase 2）

## 推荐工具

无。**此阶段禁止调用任何数据工具。** 纯推理步骤，基于 ScanFindings 中已有的数据进行分析和假设构建。

## SOP

### Step 1: 数据模式识别

分析 ScanFindings 中的：

- **传导链模式**：事件的直接影响 → 间接影响 → 二阶反馈，哪些路径已被数据证实？哪些仍是推测？
- **市场定价程度**：市场已反映多少？哪些传导路径已定价，哪些尚未定价？
- **矛盾**：不同资产/市场的反应是否矛盾？（如股市涨但债市跌；直接受益方下跌但间接受益方上涨）
- **历史类比信号**：当前事件最像历史上哪个事件？当时的市场反应和后续演化如何？
- **时间差机会**：市场是否只定价了即时冲击而忽视中期传导？

### Step 2: 构建竞争性假设

基于模式识别结果，提出 **2-4 个** 相互竞争的**事件影响假设**。

> event 假设数量与 investment 类似（2-4 个），因为事件传导路径相对收敛，不需要像 industry 那样多假设并行覆盖。

**假设构建规则**：

1. 每个假设必须标注基于哪个 D 维度（D1/D2/D3/D4）
2. 假设之间必须有张力——不能全是"影响正面"或全是"影响有限"，至少包含 1 个反向/中性假设
3. **至少 1 个假设必须来自 D4（认知差）**：识别"市场定价偏差"
4. 假设必须可证伪——不能是空泛命题（如"影响有待观察"）
5. **事件层假设，不是单股/行业层假设**：假设主语是"该事件的影响"或"传导链的某个环节"，不是"某家公司将如何"

**event 假设的常见类型**：

- **传导放大假设**："事件影响将通过 X 传导链放大，市场当前定价不足"
- **传导阻断假设**："事件直接影响显著，但间接传导将被 Y 因素阻断，影响有限"
- **二阶反馈假设**："事件本身影响可控，但引发的风险偏好/资金流动变化将产生更大影响"
- **时间差假设**："市场只定价了即时冲击，中期传导（3-6 月后）将产生更大影响"
- **过度反应假设**："市场即期反应过度，事件实际影响有限，将出现修正"
- **范式切换假设**："该事件标志着某个政策周期/监管周期的切换，后续影响将持续扩散"

**假设方向性标签**：

- `bullish`：正面假设 — 事件影响偏正面，或市场低估了正面影响
- `bearish`：负面假设 — 事件影响偏负面，或市场低估了负面影响
- `neutral`：中性假设 — 事件影响有限或已被充分定价

### Step 3: 定义可验证预测和所需证据

每个假设必须定义：

- **testable_predictions**：如果假设成立，应该能观察到什么？（具体、可量化）
  - 市场层指标：相关资产价格变动方向/幅度、波动率变化、资金流向
  - 传导层指标：间接影响方的订单/营收/利润变化方向
  - 时间层指标：影响在 N 天/周/月内显现
- **evidence_needed**：验证这个假设需要什么数据？（具体到可转化为工具查询）

evidence_needed 的质量标准：

- 必须具体到可以直接构造工具调用（如"事件后 5 个交易日相关板块资金净流入数据"，而非"市场反应数据"）
- 必须包含支撑和反驳两个方向的证据需求
- 优先列出最能区分假设真伪的关键证据

### Step 4: 标注事件范式标签

为每个假设附加一个**事件范式标签**——把假设钉到事件分析史的某类经典范式上。这个标签会沿用到 07-synthesize 报告的"历史框架"章节。

**范式选项**（必选其一或多个组合，详见 `paradigms.md`）：

- 黑天鹅 / 灰犀牛
- 政策红利 / 政策收紧
- 传染链（跨市场/跨行业传染）
- 财报冲击（超预期/低于预期）
- 监管周期切换
- 地缘政治冲击

参考 ScanFindings 中"历史类比"模块的"事件范式案例"——选与历史案例最匹配的标签，并在假设中说明匹配点。

如 event_depth_tier=lite 没有充分的历史类比，则按假设内在逻辑直接选标签。

## 产出交付物：事件影响假设矩阵

```
## 假设列表

### H1: {假设陈述}
- 类型：{bullish/bearish/neutral}
- 四维基础：{D1/D2/D3/D4}
- 范式标签：{黑天鹅 / 政策红利 / 传染链 / ...}（与历史案例的匹配点：{一句话说明}）
- 核心逻辑：{2-3 句话解释事件传导的因果链：A 事件 → B 传导 → C 影响}
- 可验证预测（事件层）：
  1. {prediction_1}（如：事件后 2 周内 X 板块资金净流入超 Y 亿）
  2. {prediction_2}（如：间接影响方 Z 公司 Q2 营收环比变化 > W%）
- 所需证据：
  - 支撑方向：{evidence_supporting}
  - 反驳方向：{evidence_refuting}

### H2: {假设陈述}
...

### H3: {假设陈述}（D4 认知差）
- 类型：{bullish/bearish/neutral}
- 四维基础：D4
- 范式标签：{...}
- 市场当前定价：{市场已反映的程度}
- 认知差点：{我们认为市场误判了什么}
- 可验证预测：...
- 所需证据：...
```

## 阶段验收标准

- 假设数量在 2-4 个之间
- 至少 1 个假设来自 D4（认知差维度）
- 至少 1 个反向/中性假设（避免全部同向）
- 每个假设都有 testable_predictions 和 evidence_needed
- 每个假设都附带事件范式标签
- 每个假设都是事件层命题，不是单股/行业层
- 满足后完成本阶段并进入阶段四

## 关键差异提示（vs investment / industry）

- **假设围绕"事件传导"**，不是"单股押注"或"行业格局"
- **假设主语是"该事件的影响"**：禁止"某家公司将如何"或"行业将如何"这种脱离事件传导的表述
- **范式库不同**：用 event/paradigms.md（黑天鹅/灰犀牛/政策红利/传染链等），不用投资史或产业演化范式
- **可验证预测的时间窗口更短**：天/周/月，不是年
- **历史类比聚焦"事件反应"**：类似事件的市场反应和后续演化，不是公司/行业的长期演化
