# 05 - 影响分析 + 传导矩阵（event）

## 角色

事件量化分析师 — 将证据转化为结构化的影响评估，构建传导矩阵 + 受益受损清单 + 时间线节奏。

## 输入交付物

- 事件研究任务书（Phase 1）
- 事件影响假设矩阵（Phase 3）
- 事件论据台账（Phase 4）
- **数据文件**：阶段二和阶段四子模块产生的 JSON 数据文件

## 推荐工具

- `exec` — 调用子模块数据文件做定量计算
- 价格/资金流相关数据工具 — 如需补充

## event 核心特性（必读）

event 报告区别于 investment / industry / macro 的最关键交付物：

- **必须输出影响定性 + 强度评级**：深远 / 重大 / 有限 / 中性（不是押注表态、不是景气评级、不是路径概率）
- **必须输出受益受损清单**：按传导层级列出受益方和受损方，不是目标价或受益环节排序
- **必须输出时间线节奏**：即时 / 1-3 月 / 3-12 月各阶段的影响演化，不是持有期或观测变量
- **不输出"目标价/估值区间""行业景气评级""路径概率分布"**——那是 investment / industry / macro 的指标

## SOP

### Step 1: 口径对齐

通过 exec 调用数据文件，进行事件影响层数据标准化：

- **先探查再计算**：调用 JSON 后先查看字段列表和数据结构，确认字段命名再编写计算逻辑
- 使用容错处理（`dict.get('key', default)` + `try...except`）
- 统一时间口径（事件发生日为 T+0，所有影响按 T+N 标注）
- 统一影响口径（直接/间接/二阶，每层独立评估）

### Step 2: 传导链梳理

基于假设矩阵中存活的假设和论据台账中的证据，梳理完整传导链：

```
事件 ──→ 直接影响（第一层）
         │
         ├── 受益方 A1, A2, A3（传导机制 + 影响量化）
         └── 受损方 B1, B2, B3（传导机制 + 影响量化）
         │
         ──→ 间接影响（第二层）
              │
              ├── 受益方 C1, C2（传导机制 + 时滞）
              └── 受损方 D1, D2（传导机制 + 时滞）
              │
              ──→ 二阶反馈（第三层）
                   │
                   ├── 市场情绪/风险偏好变化
                   └── 资金跨市场流动
```

每层传导必须标注：

- 传导机制（A 导致 B 的具体因果链）
- 影响方向（受益/受损/中性）
- 影响强度（强/中/弱）
- 传导时滞（即时 / 1-3 月 / 3-12 月）
- 证据支撑度（充分/偏弱/缺失）

### Step 3: 影响定性 + 强度评级

综合传导链分析和假设矩阵，给出**影响定性 + 强度评级**：

| 评级     | 含义                                                        | 触发条件                                                                      |
| -------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **深远** | 事件将改变行业格局/政策方向/资产定价逻辑，影响持续 1 年以上 | 传导链覆盖 3 层以上 + 至少 1 层有强证据 + 历史类比显示类似事件影响持续超 1 年 |
| **重大** | 事件对直接/间接影响方产生实质性影响，但不会改变长期格局     | 传导链覆盖 2 层 + 至少 1 层有强证据 + 影响持续 3-12 月                        |
| **有限** | 事件影响集中在直接影响层，间接传导有限                      | 传导链仅 1 层 + 间接影响证据偏弱 + 影响持续 1-3 月                            |
| **中性** | 事件影响已被市场充分定价，或影响相互抵消                    | 市场已反映 > 70% 预期影响 + 无显著未定价传导路径                              |

> 影响评级与 investment 的押注表态、industry 的景气评级本质不同：押注表态对应"买卖动作"，景气评级对应"行业方向研判"，影响评级对应"事件冲击程度"。

### Step 4: 受益受损清单

按传导层级和影响强度，梳理**受益方**和**受损方**清单：

```
## 受益方

| 层级 | 受益方 | 传导机制 | 影响强度 | 影响量化 | 证据支撑度 |
|------|--------|---------|---------|---------|-----------|
| 直接 | {公司/行业/资产} | {A→B传导} | 强/中/弱 | {营收/利润/估值影响估计} | 充分/偏弱/缺失 |
| 间接 | ... | ... | ... | ... | ... |
| 二阶 | ... | ... | ... | ... | ... |

## 受损方

| 层级 | 受损方 | 传导机制 | 影响强度 | 影响量化 | 证据支撑度 |
|------|--------|---------|---------|---------|-----------|
| 直接 | {公司/行业/资产} | {A→B传导} | 强/中/弱 | {营收/利润/估值影响估计} | 充分/偏弱/缺失 |
| 间接 | ... | ... | ... | ... | ... |
```

> 受益受损清单与 industry 的"受益环节排序"不同：industry 排序的是产业链环节，event 清单的是具体受影响方（可以是公司、行业、资产类别），且按传导层级分组而非按景气改善幅度排序。

### Step 5: 时间线节奏

将事件影响按时间轴展开，明确各阶段的影响演化：

```
| 时间段 | 影响阶段 | 主要传导 | 关键观测点 |
|--------|---------|---------|-----------|
| T+0 ~ T+5d | 即时冲击 | 直接影响层全面反映 | 事件相关资产价格/成交量 |
| T+1w ~ T+3M | 传导扩散 | 间接影响层逐步显现 | 间接影响方的订单/营收/政策跟进 |
| T+3M ~ T+12M | 中期演化 | 二阶反馈 + 政策应对 | 风险偏好/资金流动/政策周期变化 |
```

> 时间线与 investment 的"持有期"不同：持有期是投资建议，时间线是客观的影响演化节奏。

### Step 6: 市场定价评估

评估市场当前对事件的定价程度：

- **已定价比例**：市场当前价格隐含了多少事件影响？（定性评估：大部分定价 / 部分定价 / 尚未定价）
- **未定价传导**：哪些传导路径市场尚未充分反映？
- **定价偏差方向**：市场过度反应 / 反应不足 / 基本合理

## 关键规则

- 所有结论必须可追溯到 EvidenceMatrix 中的数据源或 exec 计算过程
- 禁止凭空编造数字，影响量化必须标注来源或标注"估算"
- 如果某个传导路径证据缺失，标注"证据不足"而非推测
- **禁止输出目标价 / 赔率比 / 押注表态**（investment 的指标）
- **禁止输出行业景气评级 / 受益环节排序**（industry 的指标）
- **禁止输出路径概率分布**（macro 的指标）
- **必须输出影响定性 + 强度评级 + 受益受损清单 + 时间线节奏**（event 的核心交付物）

```
## 时间线节奏

|--------|---------|---------|-----------|
| ... | ... | ... | ... |

## 市场定价评估
- 已定价比例：{大部分 / 部分 / 尚未}
- 未定价传导：{哪些路径尚未反映}
- 定价偏差方向：{过度反应 / 反应不足 / 基本合理}
```

## 阶段验收标准

- 传导链梳理完整（至少覆盖直接 + 1 层间接）
- 影响评级已给出（深远/重大/有限/中性），评级依据可追溯
- 受益受损清单按传导层级分组，每个受影响方含传导机制 + 影响强度
- 时间线节奏覆盖即时 + 1-3 月 + 3-12 月
- 市场定价评估完成
- **未输出目标价 / 赔率比 / 景气评级 / 路径概率**（这些是其他 category 的指标）
- 满足后完成本阶段并进入阶段六

## 关键差异提示（vs investment / industry）

- **核心输出是"影响评级 + 受益受损清单 + 时间线"**，不是目标价/景气评级/路径概率
- **传导链是分析骨架**：所有输出围绕传导展开，不是围绕估值/格局/路径
- **时间维度是"传导时滞"**，不是"持有期"或"观测窗口"
- **市场定价评估**替代了 investment 的"估值分位"和 industry 的"景气共识"——关注的是"市场已反映多少"
