# 04 - 证据采集（event · 按假设并行 subagent）

## 角色

证据调查团 — 为每个事件影响假设系统性、平衡地采集双向证据。

## 输入交付物

- 事件影响假设矩阵（来自 Phase 3）
- 事件信息采集底稿（来自 Phase 2）— 用于避免重复采集

## 执行模式

**按假设并行** — 为每个假设启动一个独立子模块，并行采集证据。

> event 研究的证据采集比 investment/industry 更聚焦、更轻量。事件研究时效性强，证据窗口更短，不需要 5-10 年的纵深数据。lite 档位时可将子模块任务简化。

## SOP

### Step 1: 构造子模块任务

读取假设矩阵，为每个假设构造独立的子模块任务。

**复用 Phase 2 数据**：从 ScanFindings 中提取与该假设相关的数据摘要（几行文字，非原始文件），拼入子模块指令的"已有数据"区块。子模块据此判断哪些证据已有、哪些需要新查，避免重复调用。

### Step 2: 启动子模块

为每个假设启动一个子模块，任务模板：

```
你是事件证据调查员，负责为以下事件影响假设采集支撑和反驳证据。

## 假设信息
- 假设：{statement}（事件层命题）
- 类型：{type}（bullish / bearish / neutral）
- 四维基础：{4d_basis}
- 范式标签：{paradigm_tag}
- 可验证预测：{testable_predictions}

## 已有数据（来自 Phase 2 扫描，无需重复查询）
{从 ScanFindings 中提取的与该假设相关的数据摘要}

## 所需证据（Phase 2 未覆盖，需要新查）
- 支撑方向：{evidence_needed.支撑}
- 反驳方向：{evidence_needed.反驳}

## 执行要求
1. 根据"所需证据"构造具体的工具查询，逐一调用
2. **必须双向采集**：既找支撑证据也找反驳证据，不得只找一个方向
3. 对每条证据标注：
   - 方向：支撑 / 反驳 / 中性
   - 来源：具体的工具调用和数据字段
   - 强度：强（直接事件影响数据 / 官方文件 / 一手数据）/ 中（间接推断 / 类比推断 / 二手研报）/ 弱（单一来源 / 舆情 / 纯叙事）
   - 层级：直接影响层 / 间接传导层 / 二阶反馈层
4. **优先采集直接影响层证据**：间接/二阶证据只作补充佐证
5. 如果某个方向的证据确实找不到，**不得直接标注"未找到"**。必须展示你为寻找该证据尝试过的至少 3 条具体检索 Query 或工具调用（含检索词和返回摘要），然后才能标注为"经充分搜索后未找到"
6. **禁止再 spawn 子 agent**：所有工具调用必须由你自己直接执行

## 输出格式
先列支撑证据，再列反驳证据，最后给出该假设的证据充分度评估：
- 充分：双向均有强/中证据，且至少 1 条直接影响层强证据
- 偏弱：某方向仅有弱证据，或缺乏直接影响层强证据（仅有间接/二阶层佐证）
- 缺失：某方向完全缺失证据
```

### Step 3: 汇总 EvidenceMatrix

收齐所有子模块的提交结果后，将各假设的证据摘要汇总为论据台账。

### 迭代补充模式

如果从 Phase 6（多空辩证）回退到此阶段：

- 只为 ChallengeVerdict 中标注为 Critical 缺陷的假设启动子模块
- 子模块任务中明确指出需要补充的具体证据方向
- 不重跑已有充分证据的假设

## 数据文件传递

子模块内工具调用产生的数据文件由系统自动持久化。子模块向主模块汇报时，系统自动汇总拼接：

- 数据文件绝对路径
- 记录数和文件大小
- JSON 字段结构（字段名 + 示例值）
- exec 调用模板

阶段五（量化分析）可直接通过 `exec` 的 `json.load()` 调用这些文件做定量计算。

## 产出交付物：事件论据台账

```
## H1: {假设陈述}
证据充分度：{充分/偏弱/缺失}

### Supporting
1. {证据描述} — 来源：{工具调用} | 强度：{强/中/弱} | 层级：{直接影响层/间接传导层/二阶反馈层}
2. ...

### Refuting
1. {证据描述} — 来源：{工具调用} | 强度：{强/中/弱} | 层级：{直接影响层/间接传导层/二阶反馈层}
2. ...

## H2: {假设陈述}
...

## 数据文件引用
{系统自动拼接的数据文件路径列表}
```

## 阶段验收标准

- 所有假设的子模块已提交结果
- 每个假设至少有双向证据（支撑 + 反驳 各至少 1 条）
- 每个假设的证据中至少有 1 条标注为"直接影响层"（避免全部都是间接/二阶层推断）
- 满足后完成本阶段并进入阶段五

## 关键差异提示（vs investment / industry）

- **证据强度判定的"层级"维度不同**：直接影响层 > 间接传导层 > 二阶反馈层。同样是"强"，直接影响层的"政策原文条款"比二阶反馈层的"市场情绪变化"更有说服力
- **时间窗口更短**：事件证据聚焦近期（近 1-3 个月为主），过时的证据（> 6 个月）需标注时效性
- **历史类比证据权重更高**：类似事件的实际传导数据是 event 研究的重要证据来源，比 investment/industry 更依赖类比推断
- **lite 档位可简化**：lite 档位的子模块任务可减少查询深度，聚焦直接影响层证据
