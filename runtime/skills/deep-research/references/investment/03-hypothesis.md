# 03 - 假设生成（investment）

## 角色

投资策略师 — 从扫描数据中提炼可验证的**单股押注假设**，构建竞争性多空假设集。

## 输入交付物

投资研究任务书（Phase 1）+ 投资信息采集底稿（Phase 2）

## 推荐工具

无。**此阶段禁止调用任何数据工具。** 纯推理步骤，基于 ScanFindings 中已有的数据进行分析和假设构建。

禁止调用数据工具的原因：假设必须基于已采集的数据形成，在假设形成阶段引入新数据会破坏"先扫描后假设"的方法论，导致锚定偏误。

## SOP

### Step 1: 数据模式识别

分析 ScanFindings 中的：

- **趋势**：核心财务指标(营收 / 利润 / 毛利率 / ROE / 现金流)是改善还是恶化？
- **矛盾**：不同维度数据是否冲突？(如基本面改善但资金流出；ROE 上行但毛利率下行；研报一致看多但北向减持)
- **异常**：有无偏离公司历史规律或同行表现的数据点？
- **缺口**：市场共识(D3)与商业本质 / 边际变化(D1/D2)之间有无认知差距？
- **历史类比信号**：当前数据组合最接近历史上哪个跨国对标 / 哪个投资范式？

### Step 2: 构建竞争性假设

基于模式识别结果，提出 **2-4 个** 相互竞争的**单股押注假设**。

> investment 假设数量比 industry 少（2-4 vs 3-5）。单股的押注路径相对收敛，不需要像产业研究那样多假设并行覆盖格局 / 范式 / 拐点。

**假设构建规则**：

1. 每个假设必须标注基于哪个 D 维度（D1/D2/D3/D4）
2. 假设之间必须有张力——不能全看多或全看空，至少包含 1 个反向 / 中性假设
3. **至少 1 个假设必须来自 D4（认知差）**：识别"事实与市场共识的冲突点"
4. 假设必须可证伪——不能是空泛命题(如"公司未来既有机会也有风险")
5. **单股层假设，不是行业层假设**：假设主语是"该标的"或"该公司某业务线"，不是"行业"或"产业链某环节"

**investment 假设的常见类型**：

- **业绩反转假设**："盈利底先于估值底，未来 N 个季度净利润同比触底回升"
- **估值修复假设**："当前估值已经计入悲观预期，估值有 X% 上行空间"
- **戴维斯双击假设**："业绩 + 估值同时修复，目标空间 Y%"
- **戴维斯双杀假设**："业绩与估值同时下移，下行风险 Z%"
- **特许经营 / 复利假设**："护城河支撑长期 ROIC，5 年复利空间 N 倍"
- **价值陷阱假设**："看似便宜但永久性盈利下移，应规避"
- **新业务兑现假设**："第二曲线在未来 N 个季度兑现，市场尚未定价"

**假设方向性标签**：

- `bull`：看多假设——认为市场低估了某个正面因素
- `bear`：看空假设——认为市场忽视了某个负面风险
- `neutral`：中性假设——认为当前定价基本合理但存在结构性变化

### Step 3: 定义可验证预测和所需证据

每个假设必须定义：

- **testable_predictions**：如果假设成立，应该能观察到什么？(具体、可量化)
  - 单股层指标：营收 / 利润同比、毛利率、ROE、自由现金流
  - 估值层指标：PE / PB 分位、研报目标价中位变化
  - 经营层信号：月度销量、终端动销、渠道库存、订单数据
- **evidence_needed**：验证这个假设需要什么数据？(具体到可转化为工具查询)

evidence_needed 的质量标准：

- 必须具体到可以直接构造工具调用(如"近 8 个季度毛利率分业务拆分"，而非"财务数据")
- 必须包含支撑和反驳两个方向的证据需求
- 优先列出最能区分假设真伪的关键证据

### Step 4: 标注投资范式标签

为每个假设附加一个**投资范式标签**——把假设钉到投资史的某类经典范式上。这个标签会沿用到 07-synthesize 报告的"范式标签"和"押注式核心观点"，避免最终报告凭空命名。

**范式选项**(必选其一或多个组合，详见 `paradigms.md`)：

- 戴维斯双击 / 戴维斯双杀
- 困境反转 / 困境加深
- 价值发现 / 价值陷阱
- 特许经营权(护城河复利)
- 周期反转 / 周期顶部
- 估值切换(利率 / 风险偏好驱动的风格轮动)
- 成长拐点(S 曲线起飞 / 第二曲线兑现)

参考 ScanFindings 中"历史 × 空间"模块的"投资史经典范式案例"——选与历史案例最匹配的标签，并在假设中说明匹配点(哪个历史案例、哪个时间段、哪个数据组合相似)。

如 historical_depth_tier=skip 没有充分的范式案例，则按假设内在逻辑直接选标签 + 在 06-challenge 阶段补做历史一致性审查(若可执行)。

```

  - 反驳方向：{evidence_refuting}

### H2: {假设陈述}

### H3: {假设陈述}（D4 认知差）

```

## 阶段验收标准

- 假设数量在 2-4 个之间
- 至少 1 个假设来自 D4（认知差维度）
- 至少 1 个反向 / 中性假设(避免全部同向)
- 每个假设都有 testable_predictions 和 evidence_needed
- 每个假设都附带投资范式标签 + 历史匹配点说明（skip 档位除外）
- 每个假设都是单股层命题，不是行业层
- 满足后完成本阶段并进入阶段四

## 关键差异提示（vs industry）

- **假设数量上限更低**(2-4 vs 3-5)：单股的押注路径相对收敛，不需要像产业研究那样多假设覆盖
- **假设主语必须是"该公司 / 该标的"**：禁止"行业 / 某环节将如何"这种行业层表述
- **范式库不同**：用 investment/paradigms.md（戴维斯双击 / 困境反转 / 价值陷阱 / 特许经营 / 价值发现 / 周期反转 / 估值切换 等），不用产业演化范式（成长期 / 集中度提升 / 技术替代）
- **可验证预测的指标不同**：单股层 营收 / 利润同比 / 毛利率 / ROE / PE 分位 / 研报目标价，不是行业层 CR5 / 行业 ROE 中位
- **多了 skip 档位的容错**：industry 没有 skip，investment 在短期博弈类研究中允许跳过历史范式审查
