# 02 - 信息扫描（investment · 多模块并行 subagent）

## 角色

信息扫描负责人 — 按 investment 四维维度分派子模块广撒网采集单股数据，只记录不判断。

## 输入交付物

投资研究任务书（来自 Phase 1）

## 执行模式

**多模块并行** — 按维度启动独立子模块，每个子模块负责一个维度的数据采集。

## SOP

### Step 1: 构造子模块任务

读取投资研究任务书中的四维分析维度、对标参照、历史档位，为每个维度构造子模块任务描述。

### Step 2: 启动子模块

为以下维度各启动一个子模块：

---

**子模块一(商业本质扫描)**：

```
你是信息扫描专家，负责采集 {subject}（{symbol}）的商业本质数据。
调查方向：{4d_dimensions.D1}

采集内容：
- 财报核心数据(利润表 / 资产负债表 / 现金流量表，近 8-16 个季度)
- 收入结构拆分(按业务线 / 产品 / 地区 / 客户类型)
- 成本结构拆分(原材料 / 人工 / 折旧摊销 / 营销 / 研发)
- 盈利能力指标(毛利率 / 净利率 / ROE / ROIC 历史 + 同行对比)
- 现金流质量(经营现金流 / 净利润比、自由现金流、资本开支强度)
- 产能 / 牌照 / 技术 / 渠道等约束条件相关数据
- 管理层激励、股东结构(前十大股东、机构持股、解禁安排)

要求：广撒网采集，只记录数据不做分析判断。每个调查方向至少一次工具调用。
禁止：不得再 spawn 子 agent，所有工具调用必须由你自己直接执行。
输出：按调查方向分组的数据摘要，含数据时间戳和来源。
```

---

**子模块二(边际变化扫描)**：

```
你是信息扫描专家，负责采集 {subject}（{symbol}）的边际变化数据。
调查方向：{4d_dimensions.D2}

采集内容：
- 近 12 个月所有重要公告(业绩快报、重组、定增、回购、增减持、人员变动)
- 行业新闻、竞争对手动态、产业链上下游变化
- 高频跟踪数据(月度销量、价格指数、招聘 / 招标、终端动销、批价)
- 政策 / 监管变化、关键牌照 / 资质获取或丢失
- 大客户 / 大订单变化(签单、流失、违约)

要求：聚焦"变化"和"拐点信号"，所有事件标注时间戳。
禁止：不得再 spawn 子 agent。
输出：按时间线(最近 → 较远)排列的关键变化事件和数据。
```

---

**子模块三(市场共识扫描)**：

```
你是信息扫描专家，负责采集 {subject}（{symbol}）的市场共识数据。
调查方向：{4d_dimensions.D3}

采集内容：
- 近 30-60 天主流券商研报(评级分布、目标价中位、未来 12 / 24 月盈利预测)
- 估值历史(PE / PB / PS / EV-EBITDA 近 5-10 年分位)
- 资金流向(主力净流入、北向 / 南向持仓变化、融资融券余额、龙虎榜)
- 同行估值对比(同板块、同市值、同 ROE 的对照)
- 媒体 / 研报高频叙事词(近 90 天)
- 当下市场最担忧 / 最乐观的具体点(从研报、公开访谈、雪球 / 论坛叙事中提炼)

要求：客观记录市场观点，不做自己的判断。
禁止：不得再 spawn 子 agent。
输出：市场共识��向总结 + 关键数据点 + 主流叙事词列表。
```

---

**子模块四(宏观与对标扫描)**：

```
你是信息扫描专家，负责采集 {subject}（{symbol}）的宏观环境和对标数据。

采集内容：
- 相关宏观经济指标(GDP、利率、汇率、相关大宗商品价格)
- 产业链上下游数据(上游原材料价格、下游需求景气)
- 同行业可比标的关键指标对比：{peers}（覆盖营收、利润率、ROE、估值分位、市占率）
- 跨国对标标的关键指标对比：{global_benchmarks}（同业务模式的海外标的）
- 行业整体数据(行业增速、CR5、行业平均估值)

要求：提供该标的所处宏观环境和对标参照系全景。
禁止：不得再 spawn 子 agent。
输出：宏观环境 + 上下游 + 同行 / 跨国对标对比数据。
```

---

**子模块五(历史 × 空间扫描)**：

> 给后续报告的"投资范式标签""演化路径判断""终值估计"提供原料。按 ResearchScope 中的 `historical_depth_tier` 档位执行(skip 时跳过本子模块)。

```
你是历史研究专家，负责为 {subject}（{symbol}）采集"历史 × 空间"维度的研究原料。
执行档位：{historical_depth_tier}（来自 ResearchScope）

按档位采集：

| 档位 | 采集内容 | 输出下限 |
|------|---------|---------|
| full | 【1】2-3 家跨国同类标的 10-20 年完整演化复盘(至少含 1 成功案例 + 1 失败案例，每家 ≥ 500 字，含转折点 / 估值轨迹 / 盈利轨迹 / 市占率变化 / 管理层关键决策)<br>【2】本国行业 2-3 个完整周期复盘(≥ 800 字)，标注当前位置与哪一轮最像<br>【3】3-5 个投资史经典范式案例(每个 ≥ 200 字)，来自 paradigms.md(戴维斯双击 / 困境反转 / 价值发现 / 特许经营 / 周期反转 / 估值切换 / 价值陷阱 等) | 2500 字 |
| lite | 【1】跨国类比可选，找不到合理对照需显式声明<br>【2】本国 1-2 个最相似事件 / 周期复盘(≥ 500 字)<br>【3】2-3 个投资史范式案例(每个 ≥ 200 字) | 1000 字 |
| skip | 不启动本子模块 | — |

通用要求：
- 引用具体公司名、年份、数据，禁止"日本经验表明..."这种空话
- 跨国类比要找"业务模式 + 周期阶段相似"的标的，不能简单同行业凑数
- 原料确实不存在时(如新上市标的无 N 个完整周期)必须显式声明缺失原因，禁止编造
- 数据可来自财经数据库、公开研报、公司年报等

禁止：不得再 spawn 子 agent。
输出：按【1】【2】【3】分组，开头标注本次实际执行档位。
```

### Step 3: 汇总 ScanFindings

收齐所有子模块的提交结果后，将各维度数据摘要汇总为信息采集底稿。不做分析，只做结构化整理。

## 数据文件传递

子模块内工具调用产生的数据文件由系统自动持久化。子模块向主模块汇报时，系统自动汇总数据文件路径、字段结构和 exec 调用模��。后续阶段五可直接通过 exec 调用这些文件做单股层定量计算。

## 阶段验收标准

- 所有子模块已提交结果(子模块五在 tier=skip 时不需提交)
- D1/D2/D3 三个维度均有实质数据(不要求完美，有数据即可)
- 子模块四覆盖至少 1 家同行对标 + 1 家跨国对标(若适用)
- 历史 × 空间模块按档位达标：
  - tier=full：三件事均有实质输出，总字数 ≥ 2500 字
  - tier=lite：两件事均有实质输出，总字数 ≥ 1000 字(跨国类比缺失需声明)
  - tier=skip：跳过，但需在 ScanFindings 中标注跳过原因
- 满足后完成本阶段并进入阶段三

## 关键差异提示（vs industry）

- **必有"单股财报扫描"子模块**：财报核心三表 + 收入 / 成本拆分 + ROE 历史 / 同行对比是 investment 子模块一的命脉
- **必有"单股估值分位扫描"**：D3 关注本只标的的估值历史分位、研报目标价、资金流向，不是行业平均估值或公募配置
- **历史 × 空间档位的下限略低**(full 档 2500 字 vs industry 3000 字)：individual stock 的历史复盘以"单家公司轨迹"为主，不需要 industry 那种产业链全景厚度
- **多了 skip 档位**：短期博弈 / 财报点评类研究允许跳过历史模块，industry 不允许 skip
