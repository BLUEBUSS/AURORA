# 05 - 量化分析 + 情景矩阵（investment）

## 角色

投资量化分析师 — 将证据转化为可比较的单股层定量结论，构建 **乐观 / 基准 / 悲观** 三情景矩阵 + 押注空间。

## 输入交付物

- 投资研究任务书（Phase 1）
- 多空押注假设矩阵（Phase 3）
- 投资论据台账（Phase 4）
- **数据文件**：阶段二和阶段四子模块产生的 JSON 数据文件

## 推荐工具

- `exec` — 调用子模块数据文件做单股层财务计算（核心工具）
- 估值 / 财报相关数据工具 — 如需补充

## investment 核心特性（必读）

investment 报告区别于 industry / macro / event 的最关键交付物：

- **必须输出目标价 / 估值区间**：单股可交易，目标价是押注的核心数字
- **必须输出加权目标空间百分比 + 赔率结构 + 赔率比**：07 押注表态直接引用，禁止 07 临时换算
- **必须输出押注表态(三档之一)**：高确信看多 / 中性观察 / 高确信看空
- **不输出"行业景气评级""路径概率分布""影响等级"**——那是 industry / macro / event 的指标

## SOP

### Step 1: 口径对齐

通过 exec 调用数据文件，进行单股层数据标准化：

- **先探查再计算**：调用 JSON 后先查看字段列表和数据结构，确认字段命名再编写计算逻辑
- 使用容错处理(`dict.get('key', default)` + `try...except`)，核心字段缺失时优先尝试同义字段推导
- 统一货币单位(如有跨市场对比)
- 统一时间口径(年化 / 季度化)
- 统一可比基准(同行业、同规模)

数据文件调用示例：

```python
import json
with open("{提交结果中的文件路径}", "r") as f:
    data = json.load(f)

# 单股层指标计算示例：5 年 ROE 中位
roe_series = [q['roe'] for q in data['quarters']]
roe_5y_median = sorted(roe_series)[len(roe_series) // 2]
```

### Step 2: 关键单股指标计算

**通用单股指标**：

- **盈利能力**：ROE / ROIC / 毛利率 / 净利率及其趋势
- **成长性**：营收增速 / 利润增速(同比 + 环比)
- **估值**：PE / PB / PS / EV-EBITDA 及其历史 5-10 年分位、PEG
- **现金流质量**：经营性现金流 / 净利润比、自由现金流 / 净利润比
- **杠杆与效率**：资产负债率、有息负债率、存货周转、应收周转
- **资本回报**：ROIC vs WACC、累计自由现金流再投资回报

**业务结构追加(按行业)**：

- 制造业：产能利用率、单位毛利、单吨净利
- 消费品：渠道库存、终端动销、单店收入(同店增长)
- TMT：DAU / MAU、ARPU、单位经济模型(LTV / CAC)
- 周期 / 资源：库存周期位置、商品价格曲线弹性

### Step 3: 构建 乐观 / 基准 / 悲观 三情景矩阵

基于假设矩阵中存活的假设和论据台账中的证据，构建三种单股层情景。

**每个情景必须显式声明对应的宏观假设**——禁止只用单股层变量，否则到 Phase 7 写情景章节时无法满足"宏观假设显式声明"的要求。

**乐观情景**：最乐观的假设组合成立

- 单股层假设参数(取乐观值)：营收增速、毛利率、ROE
- **宏观假设**(必填)：信用周期阶段 / 利率区间 / 行业周期位置 / 产业政策方向
- 对应的指标预测和估值倍数
- 对应的目标价
- 触发条件：什么信号出现意味着进入此情景

**基准情景**：最可能的情景

- 单股层假设参数(取中性值，基于当前趋势外推)
- **宏观假设**(必填)：同上
- 对应的指标预测和估值倍数
- 对应的目标价
- 触发条件

**悲观情景**：最悲观的假设组合成立

- 单股层假设参数(取悲观值)
- **宏观假设**(必填)：同上
- 对应的指标预测和估值倍数
- 对应的目标价
- 触发条件

### Step 4: 敏感性分析

识别对结论影响最大的 2-3 个关键变量：

- 每个变量变动 ±10% / ±20% 时，目标估值如何变化
- 标注哪个变量是"胜负手"(对结论的翻转最敏感)

### Step 5: 估值区间推导(押注核心交付物)

- 根据三情景分别推导目标价 / 估值区间
- 标注当前价格在区间中的位置
- 计算隐含的上行 / 下行空间
- **必须输出三个数字**(07 押注表态直接引用，不允许 07 临时换算)：
  - **加权目标空间百分比**：(加权目标价 - 当前价) / 当前价 × 100%
  - **赔率结构**：上行空间(乐观目标 - 当前) / 当前 vs 下行风险(悲观目标 - 当前) / 当前
  - **赔率比**：上行空间 ÷ 下行风险绝对值(如 +100% / -25% = 4:1)
- 推导时间窗口：明确 1 年 / 3 年 / 5 年视角的目标空间，而非笼统的"未来"

### Step 6: 押注表态预生成

综合三情景概率权重 + 加权目标空间 + 赔率比，给出**押注表态**：

| 表态           | 含义                                        | 触发条件                      |
| -------------- | ------------------------------------------- | ----------------------------- |
| **高确信看多** | 加权目标空间 ≥ +15%，且赔率比 ≥ 2:1         | 乐观 + 基准情景概率合计 ≥ 60% |
| **中性观察**   | 加权目标空间在 ±15% 之间                    | 三情景概率分布相对均衡        |
| **高确信看空** | 加权目标空间 ≤ -15%，且下行赔率明显大于上行 | 悲观情景概率 ≥ 50%            |

> 押注表态是 investment 报告的"行业景气评级"——直接对应"该不该买卖"的决策动作，区别于 industry 的"是否值得跟踪"。

## 关键规则

- 所有数字必须可追溯到 EvidenceMatrix 中的数据源或 exec 计算过程
- 禁止凭空编造数字，计算过程必须展示
- 如果某个指标数据缺失，标注"数据不可获取"而非估算
- **必须输出加权目标空间百分比 + 赔率结构 + 赔率比 + 押注表态**（这是 investment 的核心交付物）
- **禁止输出"行业景气评级""路径概率分布""影响等级"**(这些是 industry / macro / event 的指标)

## 阶段验收标准

- 三情景矩阵完整(乐观 / 基准 / 悲观 均有单股层假设、**宏观假设**、关键指标预测、目标价、概率权重、触发条件)
- 至少做了 1 个胜负手变量的敏感性分析
- **加权目标空间百分比、赔率结构、赔率比已计算并输出**(07 押注表态直接引用)
- **押注表态已给出**(高确信看多 / 中性观察 / 高确信看空)，依据可追溯
- 满足后完成本阶段并进入阶段六

## 关键差异提示（vs industry）

- **必输出目标价 / 估值区间 / 加权目标空间 / 赔率比**(industry 不输出，因为行业不能直接交易)
- **押注表态(高确信看多 / 中性观察 / 高确信看空)替代 industry 的景气评级(高景气 / 中性 / 承压)**：押注表态对应"买卖动作"，景气评级对应"行业方向研判"
- **不输出"关键监测变量阈值""受益环节排序"**(那是 industry 特有)
- **指标侧重单股财务**(ROE / 毛利率 / PE 分位)，不是行业层指标(CR5 / 行业 ROE 中位)
