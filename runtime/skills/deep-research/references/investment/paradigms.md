# 投资研究范式库（investment）

供 03-hypothesis 选范式标签、06-challenge 历史一致性审查、07-synthesize "历史框架与终局判断"章节使用。

每个范式包含四要素：定义、识别信号、典型案例、判别陷阱。

---

## A 类：戴维斯双击 / 双杀（业绩 × 估值的同向共振）

### A1 戴维斯双击（Davis Double Play）

**定义**：盈利向上修复 + 估值向上修复同时发生，形成上行的乘数效应——单股押注最高赔率范式。

**识别信号**：

- 净利润同比从负转正 / 增速从个位数跳到 30%+
- ROE 从历史低位向均值回升
- PE 处于历史 5-10 年分位的 20% 以下
- 行业景气从底部回升 + 龙头资本开支已触底
- 卖方研报评级从"中性"向"看多"切换中(早期信号)
- 北向 / 公募从持续减持转为净增持

**典型案例**：

- 中国神华 2016：煤炭去产能 + 业绩反转，PE 从 5 倍升至 12 倍
- 三一重工 2020-2021：工程机械周期 + 国际化兑现，业绩翻倍 + PE 翻倍
- 美国苹果 2013-2018：iPhone 出货稳定 + 服务业务兑现，PE 从 10 倍升至 18 倍

**判别陷阱**：

- 不要把"业绩底已现"和"业绩持续向上"混淆——很多反弹只是季度噪音
- 估值低分位不是充分条件——价值陷阱也常处于低分位
- 必须双轮兑现才是双击：业绩反转 + 估值切换缺一不可

---

### A2 戴维斯双杀（Davis Double Kill）

**定义**：盈利向下 + 估值向下同时发生，形成下行的乘数效应——价值陷阱前奏。

**识别信号**：

- 净利润同比连续 3-4 个季度恶化
- ROE 从均值滑向历史低位
- PE 即使在低分位也持续被压缩(估值锚下移)
- 卖方研报频繁下调目标价
- 北向 / 主力持续净流出

**典型案例**：

- 美国通用电气 2015-2018：盈利大幅下修 + 估值由溢价转折价
- 中国教培 2021：政策冲击下盈利预期归零 + 估值崩溃
- 万科 / 保利 2021-2024：地产景气下行的双杀

**判别陷阱**：

- 双杀途中常出现假反弹——切勿把估值修复反弹误判为反转
- 与"困境反转"边界：双杀是连续向下，反转是底部出现拐点信号

---

## B 类：困境反转 / 困境加深

### B1 困境反转（Turnaround）

**定义**：行业 / 公司最坏时刻已过，盈利底先于估值底，反弹序列开启。

**识别信号**：

- 行业产能开始净退出(在建工程占固定资产比例下行 + 资本开支同比转负)
- 龙头公司毛利率率先反弹(同行还在恶化)
- 库存水位见底，渠道补货意愿回升
- 大客户 / 关键合同恢复正常
- 一次性减值 / 资产处置已基本完成

**典型案例**：

- 海螺水泥 2016：水泥行业去产能后龙头率先反弹
- 三只松鼠 2023：渠道改革后单季利润反弹
- 美国 Caterpillar 2016：全球矿业 / 基建周期触底反转

**判别陷阱**：

- 困境反转和"困境加深"边界模糊——必须看龙头资本开支是否触底 + 行业供给侧是否净退出，缺一即可能仍在中段
- 短期反弹未必持续——必须有 2-3 个季度的连续验证

---

### B2 困境加深（Deteriorating）

**定义**：利空仍在累积，未到出尽——常被错认为"困境反转"。

**识别信号**：

- 行业仍在产能扩张(资本开支同比仍正)
- 龙头毛利率仍在恶化
- 渠道库存高位，无去化迹象
- 大股东 / 高管减持
- 业绩预告频繁下修

**典型案例**：

- 中国生猪养殖 2022 上半年：以为反转，实际仍在产能去化中
- 美国 Sears 2010-2018：反复"反转预期"但持续恶化至破产

**判别陷阱**：

- 容易被反弹诱多——任何下行通道里都会有 5-10 个交易日的反弹
- 真反转 vs 假反弹的关键判据：基本面驱动信号(资本开支 / 库存 / 龙头毛利率)是否同步出现

---

## C 类：价值陷阱 / 价值发现

### C1 价值陷阱（Value Trap）

**定义**：表面便宜(PE / PB 低分位)但内在价值在永久性下移——估值低不是机会而是陷阱。

**识别信号**：

- ROIC 长期低于资本成本(WACC)
- 行业总规模天花板下移(被替代品蚕食 / 需求结构性下行)
- 自由现金流持续为负或下行
- 管理层无重大改革动作
- 估值持续被压缩(每次"修复"都被新的下修取代)

**典型案例**：

- 美国 IBM 2013-2019：低估值 + 业务转型失败 + 自由现金流恶化
- 中国传统纸媒 / 传统零售 2015-2020：估值"便宜"但业务持续萎缩
- 日本传统消费电子 2000-2010 各家(夏普 / 先锋等)：低估值伴随永久性 ROE 下移

**判别陷阱**：

- 价值陷阱与"困境反转"的边界：看 ROIC 是否长期低于 WACC，是否有结构性需求恢复信号
- 估值低 + 高分红可能掩盖陷阱——分红来自存量现金而非可持续盈利

---

### C2 价值发现（Hidden Value）

**定义**：隐性资产、子公司分拆价值、非经营性资产被市场忽视——伯克希尔早年模式。

**识别信号**：

- 净资产重置成本远高于 PB 隐含市值
- 子公司单独估值合计远高于母公司市值(分类账折价)
- 持有大量货币资金 / 投资性资产被忽视
- 表外资产(矿权 / 房地产 / 牌照)账面价值显著低于市价
- 即将分拆 / 重组的事件催化

**典型案例**：

- 中国神华(2016-2017)：账上现金占市值近半被忽视
- 长江电力(早期)：现金流稳定 + 资产重置价值显著高于市值
- 美国 Berkshire Hathaway 早年(1965-1980)：纺织主业之外的隐性投资资产
- A 股部分老牌国企：地产 / 矿权 / 子公司股权被市值低估

**判别陷阱**：

- 隐性资产能否变现是关键——长期不变现的折价等于 0
- 分类账折价的"催化时点"很难预测——可能折价持续 5-10 年才兑现

---

## D 类：特许经营权（护城河复利）

### D1 特许经营权（Franchise）

**定义**：牌照 / 品牌 / 网络效应 / 转换成本支撑长期高 ROIC、可持续高增长的复利模式——巴菲特核心范式。

**识别信号**：

- ROIC 持续 ≥ 15%，且 5-10 年稳定
- 毛利率行业最高且稳定 / 抬升
- 自由现金流 / 净利润比率 ≥ 80%
- 客户留存率 / 复购率行业最高
- 龙头通过提价 / 品类延伸 / 出海持续扩张

**典型案例**：

- 贵州茅台 2010-2020：高端白酒护城河 + 提价能力
- 美国 Coca-Cola 1980-2000：品牌护城河 + 全球渠道
- 美国 Visa / Mastercard 2008-2024：网络效应 + 转换成本
- 美国 Microsoft Office / Windows 2010s：生态壁垒

**判别陷阱**：

- "护城河"叙事容易过度延伸——并非所有"龙头"都是 franchise
- 高 ROIC 必须 5-10 年验证，不能用 3 年数据判定
- 估值往往不便宜——需要等待估值切换或宏观下行让出买点

---

## E 类：周期反转 / 周期顶部

### E1 周期反转（Cyclical Recovery）

**定义**：库存 / 产能 / 信用周期触底回升，与公司基本面共振。

**识别信号**：

- 行业 PMI 上行穿越 50 / PPI 由负转正
- 行业产能利用率从低位上行
- 库存增速 - 销售增速 由正转负(去库结束)
- 大宗商品价格曲线触底(资源 / 周期类)
- 龙头开始重启资本开支

**典型案例**：

- 全球半导体周期反转(2019, 2024)
- 中国黑色金属周期反转(2015-2016)
- 全球油气周期反转(2020-2022)

**判别陷阱**：

- 周期反转与"长期牛市"不可混淆——3-4 年中周期的边界要清楚
- 押注周期反转最佳点是触底前后 6 个月，过早 = 多承担 2-3 个季度的浮亏

---

### E2 周期顶部（Cyclical Peak）

**定义**：景气周期接近顶部，资本开支 / 估值同时见高，下行风险大于上行。

**识别信号**：

- 行业资本开支同比 ≥ +30%
- 在建工程占固定资产比例处于历史高位
- 商品价格曲线已超历史长期均值 ≥ 2 个标准差
- 龙头利润率创历史新高
- 估值已接近 / 超过历史均值

**典型案例**：

- 全球航运 2021：BDI / SCFI 创历史，2022 见顶
- 中国光伏 2022：扩产潮顶部
- 全球原油 2014：油价 100 美元附近的产能扩张顶部

**判别陷阱**：

- 顶部往往持续 6-12 个月，难精确预测，但赔率不利明显
- "新范式"叙事是顶部信号——任何"这次不一样"的论证都需谨慎对待

---

## F 类：估值切换（风格轮动）

### F1 估值切换（Valuation Re-rating）

**定义**：利率 / 风险偏好 / 流动性环境改变，驱动同一标的估值倍数显著重估。

**识别信号**：

- 长端无风险利率显著变动(±100bp 以上)
- 风险偏好切换(VIX / 信用利差大幅变动)
- 行业政策定调发生切换(从"规范"转"扶持"或反向)
- 资金风格切换(成长 vs 价值的相对配置)
- 同行业 / 同类标的 PE 中枢同步迁移

**典型案例**：

- A 股 2019-2020 核心资产估值切换(贴现率下降 + 风险偏好上行)
- 美国成长股 2022 估值杀跌(联储加息 + 长端利率上行)
- 港股互联网 2021 估值切换(政策定调改变)
- A 股高股息 2024：低利率环境下的估值切换

**判别陷阱**：

- 估值切换通常伴随基本面变化，纯切换的标的稀少
- 切换的方向 / 幅度 / 时点都难精确——优势是给出"上下行不对称"的赔率结构

---

## G 类：成长拐点（S 曲线）

### G1 成长拐点（Growth Inflection）

**定义**：单股进入新一轮高成长——可能来自渗透率拐点、新品类、新市场或第二曲线兑现。

**识别信号**：

- 单位经济模型(unit economics)由负转正
- 出货 / 用户增速进入加速段
- 新业务收入占比从 < 10% 跨越 ≥ 25%
- 资本市场从给"成长溢价"的早期标志(估值上行 + 业绩上行)

**典型案例**：

- 比亚迪 2020-2022：DM-i 平台兑现 + 新能源车出货跳变
- 美国英伟达 2023+：AI 算力第二曲线兑现
- 中国安克创新 2018-2021：跨境电商出海拐点
- 中国宁德时代 2017-2020：动力电池出海拐点

**判别陷阱**：

- 成长拐点容易被"提前预测"——多数提前预测的拐点是伪拐点
- 真拐点的判别看"边际成本下降速度"而非"绝对渗透率数字"
- 第二曲线兑现需要看 ≥ 4 个季度的连续验证
