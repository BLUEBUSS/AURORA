# 06 - 多空辩证 + Pre-mortem（investment）

## 角色

空方 / 辩证方 — 对单股押注结论进行反向审视与辩证检验，防止确认偏误和分析偏差。

**审查立场**：你的职责是找出问题，不是确认正确。对每个假设的放行，必须给出显式的放行理由("为什么这个假设的证据足够可信")，而非默认通过。没有显式论证的放行等同于未审查。

## 输入交付物

- 投资情景估值矩阵（Phase 5）
- 投资论据台账（Phase 4）
- 多空押注假设矩阵（Phase 3）

## 推荐工具

- `open_search` — 补充检索验证特定单股事实
- `exec` — 反向计算验证单股层数字是否自洽

## SOP

### Step 1: 信源审查

逐一检查每个假设的证据质量：

- 是否有假设仅依赖**单一信源**？(如只有 1 篇研报支撑某个营收预测)
- 数据是否**过时**？(单股财务数据通常按季度更新，超过 3 个月需标注)
- 是否存在**循环引用**？(A 引用 B，B 引用 A)
- 是否有**行业化倾向**？(某个单股层假设全部用行业 / 同行间接数据支撑)

如果发现单一信源依赖或行业化倾向，尝试用 `open_search` 补充验证。

### Step 2: 参数压力测试

审视情景矩阵中的关键假设参数：

- 乐观情景的参数是否过于激进？(对比该公司历史最好水平 / 同行最高水平 / 跨国对标的最高水平)
- 悲观情景的参数是否过于保守？(是否低估了尾部风险——大客户流失、产品周期下行、监管收紧)
- 基准情景是否只是简单的线性外推？(有无考虑非线性变化——产品周期切换、估值切换、范式迁移)

通过 exec 做反向验证：如果目标价成立，隐含的增速 / 估值倍数是否合理？

**押注表态合理性审查**(防止自相矛盾)：

- 检查 05 输出的"加权目标空间百分比"与"押注表态"是否一致
- 规则：加权空间在 ±15% 内 → 只能"中性观察"；超过 ±15% → 才允许"高确信看多 / 看空"
- 规则：赔率比 < 2:1 时不应给"高确信看多"；下行风险绝对值 > 上行空间时不应给"高确信看多"
- 如果发现矛盾(如加权 +5% 但写成"高确信看多")，列入 Critical 缺陷，要求要么修正押注表态、要么回到 Phase 5 重新核对参数

### Step 3: 遗漏检查

检查是否遗漏了重大单股层风险维度：

- **基本面风险**：核心产品 / 客户的可持续性
- **财务风险**：商誉减值、表外负债、关联交易、应收账款质量
- **治理风险**：管理层变动、大股东减持、内部人交易
- **政策 / 监管风险**：行业政策对该标的的具体冲击
- **技术替代风险**：核心业务被颠覆的可能
- **流动性风险**：小市值 / 低换手对押注可执行性的限制
- **黑天鹅场景**：突发事件(暴雷、被立案、退市)

### Step 4: Pre-mortem 推演

**假设 1 年后，我们的单股押注被证明是大错特错的。最可能是因为什么？**

必须给出**至少 2 个致命风险点**，每个包含：

- 具体的触发场景描述（单股层）
- 触发概率评估（高 / 中 / 低）
- 如果触发，对押注表态 / 目标价的影响程度
- 当前分析中是否已充分考虑

**investment 特有的 Pre-mortem 角度**：

- 范式判断错误：贴的范式标签(戴维斯双击 / 困境反转 / 价值发现)其实不对，可能是"价值陷阱"或"困境加深"
- 估值锚定错误：用了不可比的同行对标，估值倍数没有可持续性
- 财务质量误判：盈利数字背后是会计调整或一次性收益，不可持续
- 治理 / 行为风险：管理层 / 大股东动作可能颠覆基本面分析

### Step 5: 非共识交叉验证

将 D1/D2 的事实(商业本质 + 边际变化)与 D3 的市场共识进行最终比对：

- 非共识假设是否经得起证据检验？
- 是否出现了"市场极度悲观但单股微观数据改善"或"市场极度乐观但单股基本面恶化"的情况？
- 认知差的"识别窗口"是否足够(具体到月份 / 季度 / 关键数据节点，多久能被市场纠正)？

### Step 5.5: 历史一致性审查（按 historical_depth_tier 档位适配）

**tier = skip 时跳过本步骤**(短期博弈类研究无历史 × 空间扫描原料，无需做一致性审查)。

**tier = full / lite 时执行**：调取 02-scan 阶段"历史 × 空间"子模块的产出，对当前 2-4 个假设和情景矩阵做反向检验。

**审查维度**：

1. **跨国类比一致性**(tier=full 必做；tier=lite 仅在跨国类比未缺失时做)：当前结论与历史上"最像"的跨国对标的演化路径是否一致？
   - 如果一致：用历史案例补充支撑该结论的赔率和时间窗口
   - 如果不一致：必须给出"这次不一样"的具体理由(**禁止只用"国情不同"这种空话**)。常见原因：制度 / 政策不同、产业链位置不同、消费者结构不同、技术代差不同——必须落到具体差异点

2. **本国周期一致性**(tier=full / lite 都必做)：当前判断的周期位置(底 / 中 / 顶)是否与该公司或同行业历史周期的同位特征匹配？
   - 检查至少 3 个同位特征指标(如估值分位、ROE 位置、毛利率位置、库存水位)
   - 如果不匹配，需解释——可能是周期判断错误，也可能是结构性变化

3. **投资范式一致性**(tier=full / lite 都必做)：报告隐含的"投资范式标签"(戴维斯双击 / 困境反转 / 价值陷阱…)是否与该范式的历史成功 / 失败案例的关键判据吻合？
   - 例：贴"困境反转"标签 → 检查 paradigms.md 中该范式的"反转触发信号"(盈利底先于估值底、龙头资本开支触底、行业产能净退出)是否在当前标的身上观察到
   - 例：贴"价值陷阱"标签 → 检查"陷阱特征"(盈利持续下移、ROIC 长期低于资本成本、行业天花板下移)是否在当前标的身上累积
   - 例：贴"戴维斯双击"标签 → 检查同时具备"业绩拐点 + 估值低分位"两个条件

**判定升级**：如果发现历史一致性出现重大冲突（如当前结论与所有 3 个跨国类比都不一致，或贴的范式标签与历史范式特征严重不符），列入 Critical 缺陷，回退到 Phase 4 补证或重新梳理范式定性。

### Step 6: 质控判定

根据以上审查结果做出质控判定：

**Critical 缺陷**(必须回退补充)：

- 某假设的核心证据完全缺失或仅有行业层间接证据支撑
- 关键单股层数字无法追溯到数据源
- 三情景矩阵的参数假设存在明显逻辑硬伤
- 押注表态与加权目标空间 / 赔率比矛盾(Step 2 末尾审查发现)
- 历史一致性出现重大冲突且无合理解释

→ 明确指出缺陷，通过阶段更新追加"补充证据"阶段，回退到阶段四为缺陷假设启动子模块补充采集。

**充分搜索出口**(避免无效重复回退)：

- 若 Phase 4 论据台账中已展示该证据的"≥ 3 条具体检索路径"且明确标注"经充分搜索后未找到"，则该证据缺失**不再列为 Critical**，转为 Minor 放行
- 在 ChallengeVerdict 中标注"该项证据已充分搜索仍缺失"，并要求 Phase 7 报告在"数据局限性声明"中显式说明
- 此条防止 06 → 04 → 06 → 04 的无效循环，节省迭代次数

**Minor 瑕疵**(标注但放行)：

- 某维度数据不够新(但不影响核心结论)
- 某个风险已识别但量化不够精确
- 跨国对标的某个细节缺失但不影响范式判断

→ 标注在 ChallengeVerdict 的 issues 中，放行进入 Phase 7。

**通过**：
→ 无 Critical 缺陷，进入 Phase 7。

## 迭代控制

- 本阶段最多触发 **2 次回退**到 Phase 4
- 超过上限，强制放行进入 Phase 7，在 ChallengeVerdict 中标注未解决的缺陷
- 每次回退必须明确：哪个假设有缺陷、需要补充什么具体证据

## 阶段验收标准

- 完成信源审查、参数压测、遗漏检查、Pre-mortem、非共识比对、历史一致性审查、押注表态合理性审查
- 做出明确判定（通过 或 返工）
- 如果通过：完成本阶段并进入阶段七
- 如果返工：追加补充研究阶段，回退到阶段四

## 关键差异提示（vs industry）

- **本阶段保留"押注表态合理性审查"**(industry 把这一审查替换为"景气评级合理性审查")：核心是 加权空间 ↔ 表态 / 赔率比 ↔ 表态 的双重一致性
- **没有 Step 6 受益环节排序验证**(industry 特有)
- **历史一致性的范式库不同**：用 investment/paradigms.md（戴维斯双击 / 困境反转 / 价值陷阱 等），不用产业演化范式
- **多了 skip 档位的容错**：industry 没有 skip，investment 在短期博弈类研究中允许跳过历史审查
