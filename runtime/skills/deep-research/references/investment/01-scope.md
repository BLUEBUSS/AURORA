# 01 - 研究定界（investment）

## 角色

研究规划师 — 将模糊的标的投资研究请求转化为结构化的 ResearchScope，用 investment 四维框架构建分析维度。

## 输入交付物

用户原始研究请求（如"深度研究比亚迪的投资价值""贵州茅���能不能买""中海油 2026 年配置价值"）。

## 推荐工具

- `open_search` — 快速了解标的背景、近期热点、可比标的清单

## SOP

### Step 0: 研究目标澄清（如需）

如果用户请求中以下信息不明确，**必须先用 assistant 文本提问澄清**，收到回复后再继续：

- **具体标的不明**：只说了行业/板块没给具体标的（例："白酒哪只能买"→ 需用户给候选清单或同意先做 industry）
- **关注重点不明**：没说关注维度（估值合理性 / 成长性 / 困境反转 / 第二曲线 / 风险评估……至少锁定 1 个）
- **押注方向不明**：没说是买入决策 / 持仓评估 / 卖出决策 / 估值再认知

**澄清话术示例（用户输入"分析一下茅台"）**：

```
投资研究茅台之前需要确认：

1. **关注重点是什么？**
   - 当前估值是否合理
   - 第二曲线（系列酒 / 海外 / 直销占比提升）
   - 困境反转（如果近期下跌较多）
   - 长期护城河与复利空间

时间视角默认 1-3 年，如需调整请补充。
```

如果用户请求已明确（如"茅台现在能不能买，估值合理吗"），直接进入 Step 1。

### Step 1: 解析投资研究请求

从用户请求中提取：

- **研究对象**：单一标的（个股 / 债券 / 商品 / 可转债 / 基金）
- **隐含的押注方向**：买入决策 / 持仓评估 / 卖出决策 / 估值再认知
- **时间范围**：默认近 1-3 年回顾 + 前瞻 1-3 年（押注的持有期通常短于行业研究）

### Step 2: 确认基本档案

调用工具确认研究对象的基本档案。个股需确认：

- 股票代码、市场（A / HK / US / 港美中概）
- 行业分类（GICS / 申万 / 中信）
- 市值规模、自由流通市值
- 上市时长、近 12 个月日均成交额（流动性）
- 主要股东结构 + 关联交易概况

如为债券、商品等其他标的，按其属性建立等价档案（评级、期限、对应商品的全球供需结构等）。

### Step 3: 用 investment 四维框架构建分析维度

针对该标的，逐一定义四个维度的具体调查方向。**注意 investment 四维的命名落点是"单家公司 / 单一标的"层**——D1 是公司商业本质（不是产业本质），D3 是单股估值共识（不是行业景气共识）。

**D1 商业本质（Business Primitives）— "这家公司到底如何赚钱？"**

- **收入模型**：谁付钱？一次性 vs 复购？价格驱动 vs 销量驱动？
- **成本结构**：固定 vs 可变？规模效应曲线是否存在？
- **扩张约束**：产能 / 牌照 / 技术 / 资金 / 渠道——主要瓶颈在哪？
- **盈利质量**：毛利率 / 净利率 / ROE / ROIC 的历史水平和波动
- **自由现金流**：经营性现金流 vs 净利润的关系，资本开支强度

**D2 边际变化（The Delta）— "这家公司现在发生了什么改变？"**

- **向上催化剂**：新产品 / 新市场 / 新客户 / 成本下移 / 行业景气拐点
- **向下破坏者**：竞争加剧 / 关键大客户流失 / 政策收紧 / 技术替代
- **高频验证信号**：月度销量、招聘 / 招标数据、终端动销、批价
- **管理层变动 / 股东行为**：增减持、回购、限售解禁

**D3 市场共识（Consensus Mapping）— "当前股价里包含了什么预期？"**

- **估值分位**：PE / PB / PS / EV-EBITDA 的历史 5-10 年分位
- **卖方一致预期**：评级分布、目标价中位、未来 1-2 年盈利预测中位
- **资金行为**：北向 / 南向、主力 / 融资融券、龙虎榜
- **叙事共识**：媒体 / 研报当下高频词（"困境反转""出海""第二曲线"等）
- **市场情绪**：当下最担忧 / 最乐观的具体点（如"Q3 业绩低于预期""新产品兑现度"）

**D4 认知差预判（Variant Perception）— "我们的判断和市场可能哪里不同？"**

- **初步判断**：市场可能高估 / 低估了什么具体变量？
- **冲突点假设**：D1/D2 的事实和 D3 的共识有无明显矛盾？
- **被忽视的资产 / 业务**：表外资产、子公司分拆价值、隐性护城河

### Step 4: 补充维度检查

对照个股研究 checklist，检查四维是否有遗漏：

- ✅ 财务表现（营收 / 利润 / 现金流 / ROE 趋势）
- ✅ 竞争格局（核心对手、市占率、护城河）
- ✅ 估值水平（绝对 + 相对，含历史与同行对比）
- ✅ 成长催化剂（短中长三段）
- ✅ 风险因素（基本面 / 财务 / 治理 / 政策 / 流动性）
- ✅ 治理结构（股东结构、管理层激励、关联交易）

如为非标准标的（可转债 / 基金 / 商品），**必须自主从至少 4 个独立角度构建分析框架**。

### Step 5: 定义研究边界

- **对标参照系**：
  - 同行业可比标的（A 股 / 港股 / 美股各列至少 1 家）
  - 跨国对标（同业务模式的海外标的）
  - 历史阶段对比（本标的历史上类似估值 / 业绩组合的时点）
- **排除范围**：明确不分析的子业务 / 子标的（避免发散）
- **关注重点**：用户最关心的 1-3 个核心问题（"是否能买""跌到什么位置""持有周期"等）

### Step 6: 决定历史 × 空间扫描档位（historical_depth_tier）

| 标的特征                                          | 默认档位 | 含义                                              |
| ------------------------------------------------- | -------- | ------------------------------------------------- |
| 标的所处行业 ≥ 10 年历史，且有 1+ 完整周期可复盘  | **full** | 三件事全做：跨国 + 本国周期 + 投资史范式案例      |
| 标的所处行业 5-10 年历史，跨国对标可能不够完整    | **lite** | 本国类似阶段 + 投资史范式为主，跨国类比缺失需声明 |
| 新上市 / 新模式标的（行业 < 5 年）                | **lite** | 同上，跨国类比降级                                |
| 短期博弈（用户明确"快速分析""短线" / 财报点评型） | **skip** | 跳过子模块五；07 报告章节降级为简短参照段         |

> 档位决定下游 02-scan 子模块五的采集力度和 07-synthesize "历史框架"章节的深度。

## 阶段验收标准

- core_questions 非空（至少 1 个）
- 标的基本档案清晰（代码、市场、行业、市值、流动性）
- 四维维度每个至少有 1 个具体调查方向
- 已确定 historical_depth_tier 档位并写明决策依据
- 满足后完成本阶段并进入阶段二

## 关键差异提示（vs industry）

- **研究对象是"一家公司 / 一只标的"，不是"一个行业"**：��有维度的描述都落到单家公司层
- **D3 是"单股估值共识"**：估值历史分位、卖方目标价、资金行为；不是行业景气共识 / 公募配置
- **D4 预设方向是"市场对这只标的的具体变量错误"**，不是行业层判断错误
- **新增"流动性"考量**：小市值低换手会影响押注的可执行性，行业研究不需要这维度
