# PDF 设计系统参考

本文档为机构级研报 PDF 的设计规范源文件。Claude 在执行 PDF 渲染时读取此文件以确定视觉参数。

---

## 一、设计哲学

| 原则                  | 定义                                                          | 执行标准                                  |
| --------------------- | ------------------------------------------------------------- | ----------------------------------------- |
| **模块化（Modular）** | 任何报告由独立功能模块拼装而成                                | 模块可跨场景复用，插入/删除不影响整体排版 |
| **信息层级显性化**    | 通过视觉权重自然引导阅读顺序                                  | 3秒内定位核心结论，30秒内理解逻辑骨架     |
| **数据可溯源**        | 所有数据必须能在3步内找到原始出处                             | 统一标注系统，图表与脚注联动              |
| **场景自适应**        | 同一规范下，四种场景（个股/行业/事件/宏观）自动适配密度与结构 | 通过"内容密度系数"调节留白与图表占比      |

## 二、排版规范系统

### 2.1 字体栈（Font Stack）

| 用途             | 中文字体        | 英文字体                  | 字号    | 字重    | 行距 |
| ---------------- | --------------- | ------------------------- | ------- | ------- | ---- |
| 大标题（封面）   | STHeiti / 黑体  | Helvetica Neue            | 18-22pt | Bold    | 1.2  |
| 一级标题（章节） | STHeiti         | Helvetica Neue            | 14-16pt | Bold    | 1.3  |
| 二级标题（小节） | STHeiti         | Helvetica Neue            | 12pt    | Bold    | 1.3  |
| 三级标题（段落） | STHeiti         | Helvetica Neue            | 10.5pt  | Medium  | 1.3  |
| 正文             | SongtiSC / 宋体 | Times New Roman           | 10.5pt  | Regular | 1.5  |
| 图表文字         | STHeiti         | Arial                     | 8-9pt   | Regular | 1.2  |
| 脚注/来源        | SongtiSC        | Times New Roman           | 8pt     | Regular | 1.2  |
| 等宽数据         | —               | Courier New / Roboto Mono | 9-10pt  | Regular | 1.0  |

**强制规则**：全文档字体种类不超过3种；等宽字体仅用于财务数据与代码公式。

### 2.2 页面参数（A4标准）

| 参数     | 标准值                                    | 说明                            |
| -------- | ----------------------------------------- | ------------------------------- |
| 页面尺寸 | A4 (210×297mm)                            | 竖版为主，跨页大图可横版        |
| 页边距   | 上2.54cm / 下2.54cm / 左3.17cm / 右3.17cm | 左侧预留装订线0.5cm             |
| 正文栏宽 | 单栏16cm                                  | 双栏时每栏7.5cm，栏间距1cm      |
| 页眉     | 距顶1.5cm，高0.8cm                        | 左侧机构/作者，右侧报告标题缩写 |
| 页脚     | 距底1.5cm，高0.8cm                        | 居中页码，可选两侧合规信息      |

### 2.3 标题层级系统

采用 `"数字-字母-罗马"` 混合编码，严格对应缩进：

```
1. 一级标题（顶格，段前18pt，段后12pt，下划线分隔）
   1.1 二级标题（缩进0cm，段前12pt，段后6pt）
       1.1.1 三级标题（缩进0.5cm，段前6pt，段后3pt）
           正文首行缩进0.74cm（2字符），段后6pt
```

**视觉区分**：

- 一级标题下方加 0.75pt 单线（色值 `#003366`，宽通栏）
- 二级标题加 左侧色块（宽3pt，高随文字，色值 `#003366`）
- 三级标题使用 加粗 或 深蓝着色（`#003366`）

## 三、色彩系统

### 3.1 主色板（Primary Palette）

| 角色   | 色值      | 用途                                         |
| ------ | --------- | -------------------------------------------- |
| 机构蓝 | `#003366` | 大标题、一级标题下划线、页眉线、核心图表主色 |
| 深灰   | `#333333` | 正文文字、二级标题                           |
| 中灰   | `#666666` | 三级标题、图表注释、脚注                     |
| 浅灰   | `#F5F5F5` | 表格隔行底色、引用块背景、模块分区背景       |
| 纯白   | `#FFFFFF` | 页面底色                                     |

### 3.2 功能色板（Functional Palette）

| 角色      | 色值      | 用途                                   |
| --------- | --------- | -------------------------------------- |
| 买入/增持 | `#CC0000` | 评级标签、目标价上调箭头、看涨逻辑标记 |
| 中性/持有 | `#FF9900` | 中性评级、观望标记                     |
| 减持/卖出 | `#009900` | 卖出评级、目标价下调箭头、看跌逻辑标记 |
| 风险提示  | `#FF6600` | 风险警示框、重要假设前提               |
| 数据高亮  | `#FFF2CC` | 表格中关键假设单元格、需关注数据       |
| 超链接    | `#0066CC` | 电子文档中的引用链接                   |

**强制规则**：功能色仅用于指定场景，禁止在正文中随意使用彩色文字。

### 3.3 图表色板（Chart Palette）

标准序列（最多6色循环）：

1. `#003366`（机构蓝）
2. `#4472C4`（中蓝）
3. `#ED7D31`（橙）
4. `#A5A5A5`（灰）
5. `#FFC000`（金黄）
6. `#5B9BD5`（浅蓝）

扩展序列：使用同色系渐变（如蓝系：`#003366` → `#4472C4` → `#5B9BD5` → `#B4C7E7`）

**禁止**：红绿同时用于非评级场景（避免色盲误读）

## 四、图表与数据规范

### 4.1 表格规范（Table Standard）

**三线表变体（金融增强版）**：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 顶线：1.5pt 机构蓝 #003366
  表头行：黑体 9pt 加粗 白色文字 机构蓝底色
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 表头下线：0.75pt 机构蓝
  数据行1：宋体 9pt 常规 文字左对齐/数字右对齐
  数据行2：宋体 9pt 常规 浅灰底色 #F5F5F5（隔行变色）
  ...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 底线：1.5pt 机构蓝 #003366
数据来源：Wind，公司公告，截至2026-04-30    ← 脚注：8pt 中灰，左对齐
```

**数字格式**：

- 金额：百万/亿单位统一，保留1位小数（如 `1,234.5 百万`）
- 百分比：保留1位小数（如 `12.3%`）
- 比率：保留2位小数（如 `0.85x`）
- 日期：统一 `YYYY-MM-DD` 格式

### 4.2 图形规范（Chart Standard）

| 图表类型    | 使用场景                           | 设计规则                                                      |
| ----------- | ---------------------------------- | ------------------------------------------------------------- |
| 折线图      | 时间序列（股价/财务指标/宏观数据） | 线条≥1.5pt；数据点标记直径3pt；最多4条线；图例置于底部或右侧  |
| 柱状图      | 对比/构成（营收结构/市场份额）     | 柱宽=柱间距×0.6；使用标准色板前4色；数值标签置于柱顶          |
| 饼图/环形图 | 结构占比（业务/成本/资产结构）     | 最多6块；按大小顺时针排列；百分比标签直接标注于扇区           |
| 散点图      | 矩阵定位（估值-增速/景气度-市值）  | 象限分割线用虚线（0.5pt 中灰）；数据点可加公司代码标签        |
| 热力图      | 多维度对比（行业评分/相关性矩阵）  | 色阶：蓝（低）→白（中）→红（高）；单元格内标注数值            |
| 流程/逻辑图 | 商业模式/产业链/传导机制           | 矩形框圆角2pt，箭头≥1pt；节点文字不超过两行；统一使用机构蓝系 |

### 4.3 数据标注系统（Citation System）

三级标注体系：

| 级别       | 格式                      | 位置               | 用途                     |
| ---------- | ------------------------- | ------------------ | ------------------------ |
| A级-即时注 | `（Wind, 2026Q1）`        | 紧跟数据后，括号内 | 高频数据源，正文内不重复 |
| B级-脚注   | `¹ 详见公司2025年年报P23` | 页面底部           | 具体出处、计算方法说明   |
| C级-附录源 | `[附录3-数据来源表]`      | 文末附录           | 完整数据清单、模型假设   |

## 五、封面设计（Institutional 类型）

`institutional` 封面模式：

- **背景**：纯白 `#FFFFFF`
- **顶部**：8px 高机构蓝 `#003366` 横条（全宽）
- **主体**：居中偏上垂直堆叠
  - 标签：`深度研究报告`（10pt，机构蓝，字间距加宽）
  - 标题：大字号黑体 Bold（36pt，深灰 `#003366`）
  - 分隔线：80px 宽，2px 高，机构蓝
  - 副标题（可选）：13pt 中灰
  - 作者 + 日期：12pt
  - 核心观点摘要（可选）：浅灰背景框 + 左侧3px机构蓝竖线
- **底部**：40px 处细灰线分隔 + 合规声明（左）+ 日期（右）
- **无**：渐变、阴影、装饰图案、图片

## 六、Callout Severity 映射

在 `content.json` 中，`callout` 块支持 `severity` 字段控制边框颜色：

| severity           | 边框颜色  | 背景      | 语义           |
| ------------------ | --------- | --------- | -------------- |
| `buy` / `bullish`  | `#CC0000` | 默认      | 买入/增持/看涨 |
| `neutral`          | `#FF9900` | 默认      | 中性/持有      |
| `sell` / `bearish` | `#009900` | 默认      | 减持/卖出/看跌 |
| `risk`             | `#FF6600` | 默认      | 风险提示       |
| `highlight`        | `#003366` | `#FFF2CC` | 数据高亮       |
| 省略 / 其他        | `#003366` | 默认      | 一般洞察       |

## 七、质量门槛

PDF 通过标准：符合机构研报排版惯例，可直接用于内部讨论或客户交付。

具体：

- 封面简洁专业，无"通用 AI 输出"痕迹
- 中文字体正确渲染，无 tofu（□）
- 标题编号连续正确（1. → 1.1 → 1.1.1）
- 表格三线规范，数字对齐正确
- 图表配色统一，色盲友好
- 页码连续，页眉页脚信息完整
