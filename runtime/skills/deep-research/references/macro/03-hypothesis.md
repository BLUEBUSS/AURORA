# 03 - 假设生成（macro）

## 角色

宏观策略师 — 从扫描数据中提炼可验证的**宏观路径假设**，构建竞争性路径假设集。

## 输入交付物

宏观研究任务书（Phase 1）+ 宏观信息采集底稿（Phase 2）

## 推荐工具

无。**此阶段禁止调用任何数据工具。** 纯推理步骤，基于 ScanFindings 中已有的数据进行分析和假设构建。

## SOP

### Step 1: 数据模式识别

分析 ScanFindings 中的：

- **宏观状态定位**：当前处于哪个宏观周期位置？（扩张/放缓/衰退/复苏）
- **边际变化方向**：哪些宏观变量正在加速/减速/拐点？
- **政策反应函数**：央行/政府面对当前数据会如何反应？
- **市场预期偏差**：市场定价的宏观路径与数据/政策反应函数隐含的路径有无差异？
- **历史类比信号**：当前宏观组合最像历史上哪个时期？

### Step 2: 构建竞争性路径假设

基于模式识别结果，提出 **2-4 个** 相互竞争的**宏观路径假设**。

> macro 假设数量与 investment 类似（2-4 个），因为宏观路径虽然复杂但核心分歧通常收敛到 2-3 条。

**假设构建规则**：

1. 每个假设必须标注基于哪个 D 维度（D1/D2/D3/D4）
2. 假设之间必须有张力——不能全是同一条宏观路径，至少包含 1 条偏离路径
3. **至少 1 个假设必须来自 D4（认知差）**：识别"市场预期偏差"
4. 假设必须可证伪——不能是空泛命题（如"宏观前景不确定"）
5. **宏观路径假设，不是单股/行业/事件假设**：假设主语是"宏观变量/政策路径/周期位置"

**macro 假设的常见类型**：

- **基准路径假设**："当前宏观状态将在 X 政策下延续 Y 趋势，Z 变量将沿着 A 路径演化"
- **再通胀路径假设**："通胀将因 X 因素而二次抬头，迫使央行 Y 反应"
- **衰退路径假设**："增长将因 X 传导而放缓至衰退，央行将 Y 应对"
- **政策转向假设**："央行将在 X 条件下从紧缩转向宽松（或反向）"
- **外部冲击路径假设**："X 外部因素将打破当前宏观均衡，导致 Y 路径"

**假设方向性标签**：

- `base`：基准路径假设 — 认为最可能的宏观演化路径
- `upside`：上行偏离假设 — 比基准更乐观的宏观路径
- `downside`：下行偏离假设 — 比基准更悲观的宏观路径

### Step 3: 定义可验证预测和所需证据

每个假设必须定义：

- **testable_predictions**：如果假设成立，应该能观察到什么？（具体、可量化）
  - 宏观层指标：GDP 增速、CPI、政策利率、失业率、信用增速的演化方向
  - 市场层指标：利率曲线形态变化、信用利差变化、汇率变化
  - 政策层信号：央行声明措辞变化、投票记录变化、前瞻指引调整
- **evidence_needed**：验证这个假设需要什么数据？（具体到可转化为工具查询）

evidence_needed 的质量标准：

- 必须具体到可以直接构造工具调用（如"未来 3 个月 FOMC 会议的利率决策和声明措辞变化"，而非"政策数据"）
- 必须包含支撑和反驳两个方向的证据需求
- 优先列出最能区分假设真伪的关键证据

### Step 4: 标注宏观范式标签

为每个假设附加一个**宏观范式标签**——把假设钉到宏观分析史的某类经典范式上。这个标签会沿用到 07-synthesize 报告的"历史框架"章节。

**范式选项**（必选其一或多个组合，详见 `paradigms.md`）：

- 再通胀 / 衰退 / 滞胀
- 流动性宽松 / 流动性紧缩
- 风险偏好抬升 / 风险偏好收缩
- 信用扩张 / 信用收缩
- 软着陆 / 硬着陆

参考 ScanFindings 中"历史周期与跨国对标"模块的"宏观范式案例"——选与历史案例最匹配的标签，并在假设中说明匹配点。

如 macro_depth_tier=lite 没有充分的历史类比，则按假设内在逻辑直接选标签。

## 产出交付物：宏观路径假设矩阵

```
## 假设列表

### H1: {基准路径假设陈述}
- 类型：base
- 四维基础：{D1/D2/D3/D4}
- 范式标签：{软着陆 / 流动性宽松 / ...}（与历史案例的匹配点：{一句话说明}）
- 核心逻辑：{2-3 句话解释宏观路径的因果链：A 状态 → B 政策反应 → C 演化结果}
- 可验证预测（宏观层）：
  1. {prediction_1}（如：未来 2 个季度 GDP 增速维持在 X-Y% 区间）
  2. {prediction_2}（如：央行在未来 6 个月内降息 Z 个基点）
- 所需证据：
  - 支撑方向：{evidence_supporting}
  - 反驳方向：{evidence_refuting}

### H2: {上行/下行偏离假设陈述}
- 类型：{upside / downside}
- 四维基础：{D1/D2/D3/D4}
- 范式标签：{再通胀 / 衰退 / ...}
- 核心逻辑：...
- 可验证预测：...
- 所需证据：...

### H3: {认知差假设陈述}（D4）
- 类型：{base / upside / downside}
- 四维基础：D4
- 范式标签：{...}
- 市场当前预期：{市场定价的宏观路径}
- 认知差点：{我们认为市场预期错在哪里}
- 可验证预测：...
- 所需证据：...
```

## 阶段验收标准

- 假设数量在 2-4 个之间
- 至少 1 个假设来自 D4（认知差维度）
- 至少 1 个偏离路径假设（upside 或 downside，避免只有基准路径）
- 每个假设都有 testable_predictions 和 evidence_needed
- 每个假设都附带宏观范式标签
- 每个假设都是宏观层命题，不是单股/行业/事件层
- 满足后完成本阶段并进入阶段四

## 关键差异提示（vs investment / industry / event）

- **假设围绕"宏观路径"**，不是"单股押注""行业格局"或"事件传导"
- **假设主语是"宏观变量/政策路径"**：禁止"某家公司将如何"或"某行业将如何"
- **范式库不同**：用 macro/paradigms.md（再通胀/衰退/滞胀/流动性/风险偏好等），不用投资史/产业演化/事件范式
- **可验证预测的指标是宏观变量**：GDP/CPI/利率/汇率/信用增速，不是单股PE/行业CR5/事件传导
- **假设方向标签不同**：base/upside/downside（路径方向），不是bull/bear/neutral（押注方向）或bullish/bearish/structural（格局方向）
