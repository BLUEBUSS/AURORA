# 01 - 研究定界（macro）

## 角色

研究规划师 — 将模糊的宏观策略/利率/汇率研究请求转化为结构化的 ResearchScope，用 macro 四维框架构建分析维度。

## 输入交付物

用户原始研究请求（如"美联储降息节奏研判""信用周期当前定位""人民币汇率走势分析""全球流动性环境判断"）。

## 推荐工具

- `open_search` — 快速了解宏观环境背景、近期政策动态、市场预期

## SOP

### Step 0: 研究目标澄清（如需）

如果用户请求中以下信息不明确，**必须先用 assistant 文本提问澄清**，收到回复后再继续：

- **宏观主题过宽**：只说了大方向没聚焦具体路径（例："看下利率"→ 是降息节奏？收益率曲线？信用周期？）
- **空间范围不明**：没说是哪个经济体/市场（全球/美国/中国/欧洲/新兴市场）
- **决策用途不明**：没说是资产配置/风险评估/政策预判

**澄清话术示例（用户输入"看下利率走势"）**：

```
利率研究范围较广，需要先聚焦您的关注点：

1. **具体关注哪方面？**
   - 美联储降息节奏与路径预判
   - 中国 LPR/MLF 走势与信用周期
   - 收益率曲线形态变化
   - 全球利率联动与资本流动

2. **关注的空间范围？**
   - 美国
   - 中国
   - 全球/跨市场联动

时间视角默认中期（6-18 个月），如需调整请补充。
```

如果用户请求已明确（如"美联储下半年降息节奏预判，对新兴市场资产配置的影响"），直接进入 Step 1。

### Step 1: 解析宏观研究请求

从用户请求中提取：

- **研究对象**：宏观变量/政策/周期（利率/汇率/信用周期/通胀/增长/流动性/风险偏好）
- **空间范围**：全球 / 美国 / 中国 / 欧洲 / 新兴市场 / 跨市场
- **隐含的研究目标**：路径判断 / 政策预判 / 资产配置 / 风险评估
- **时间范围**：宏观研究默认中期为主（6-24 个月前瞻），部分需延展至长期（3-5 年）

### Step 2: 锁定宏观边界

调用工具确认宏观环境的基本信息：

- **当前宏观状态**：增长/通胀/就业/利率/汇率的最新读数和趋势
- **政策立场**：央行最新政策利率/决策声明/前瞻指引
- **市场定价**：期货市场隐含的政策路径/利率预期/汇率预期
- **关键节点**：未来 6-12 个月的重要政策会议/数据发布/事件日历

如果是跨市场/全球宏观研究，需要明确各市场/经济体的关联结构。

### Step 3: 用 macro 四维框架构建分析维度

针对该宏观课题，逐一定义四个维度的具体调查方向。**注意 macro 四维的命名和 investment/industry/event 不同**——D1 是宏观状态（不是商业本质/产业本质/事件定性），D3 是市场预期（不是估值共识/景气共识/市场定价）。

**D1 宏观状态（Macro State）— "当前宏观处于什么位置？"**

- **增长与通胀**：实际 GDP 增速/趋势、CPI/PCE/核心通胀水平与趋势、产出缺口
- **劳动力市场**：就业/失业率/薪资增速/劳动参与率
- **金融条件**：实际利率/信用利差/流动性指标/金融条件指数
- **外部平衡**：经常账户/资本流动/汇率/外债

**D2 边际变化与政策反应函数（The Delta & Policy Reaction Function）— "什么在变？央行/政府会如何反应？"**

- **边际变化**：最新数据相对预期的偏差、趋势加速/减速/拐点信号
- **政策反应函数**：央行/政府的决策规则（通胀偏好/就业偏好/金融稳定偏好）
- **政策约束**：财政空间/政治约束/外部约束（如汇率稳定 vs 货币独立）
- **政策传导机制**：政策变化如何传导至实体经济和金融市场

**D3 市场预期（Market Expectations）— "市场定价了什么？"**

- **利率预期**：期货/远期市场隐含的政策路径
- **通胀预期**：盈亏平衡通胀率/调查预期/通胀互换
- **增长预期**：卖方一致预期/PMI 预期/消费者信心
- **风险定价**：VIX/信用利差/期限利差/新兴市场利差
- **仓位与情绪**：CTFC 持仓/基金经理调查/资金流向

**D4 认知差预判（Variant Perception）— "市场预期可能错在哪里？"**

- **初步判断**：市场可能过度定价/定价不足了什么宏观路径？
- **政策预期差**：市场对央行反应函数的假设是否正确？
- **通胀预期差**：市场是否低估/高估了通胀的持续性或回落速度？
- **增长预期差**：市场是否过度外推了当前趋势？

### Step 4: 补充维度检查

对照宏观研究 checklist，检查四维是否有遗漏：

- ✅ 增长与通胀（当前状态 + 边际变化）
- ✅ 政策立场与反应函数（央行/财政）
- ✅ 金融条件与流动性
- ✅ 外部环境与跨境传导
- ✅ 市场预期与仓位

如果是跨市场/全球宏观研究，**必须自主从至少 4 个独立角度构建分析框架**。

### Step 5: 定义研究边界

- **对标参照系**：
  - 历史宏观周期类比（本经济体历史上类似阶段）
  - 跨国宏观类比（其他经济体类似宏观状态的处理方式）
  - 政策规则参照（泰勒规则/财政规则等）
- **排除范围**：明确不分析的宏观变量/市场/传导路径（避免发散）
- **关注重点**：用户最关心的 1-3 个核心问题

### Step 6: 决定研究深度档位（macro_depth_tier）

| 宏观课题特征                              | 默认档位 | 含义                                       |
| ----------------------------------------- | -------- | ------------------------------------------ |
| 核心宏观路径判断（利率/通胀/增长方向）    | **full** | 完整路径分析 + 历史周期类比 + 政策规则参照 |
| 单一宏观变量点评（某次数据发布/政策会议） | **lite** | 聚焦直接影响 + 简要历史参照，传导链可简化  |
| 跨市场/全球宏观（涉及多经济体联动）       | **full** | 需要覆盖多市场传导 + 历史周期对比          |

> 档位决定下游 02-scan 采集力度、07-synthesize 报告字数下限。

## 产出交付物：宏观研究任务书

```
研究对象：{macro_subject}（如"美联储降息路径""中国信用周期""全球流动性"）
空间范围：{全球 / 美国 / 中国 / 欧洲 / 新兴市场 / 跨市场}
当前宏观状态摘要：{增长/通胀/政策利率/金融条件 一句话概括}
research_category：macro
macro_depth_tier：{full | lite}（决策依据：{reason}）

核心问题：
1. {core_question_1}
2. {core_question_2}
3. {core_question_3}

macro 四维分析维度：
D1 宏观状态：{具体调查方向}
D2 边际变化与政策反应函数：{具体调查方向}
D3 市场预期：{具体调查方向}
D4 认知差预判：{初步方向}

对标参照：
- 历史周期类比：{similar_cycles}
- 跨国类比：{cross_country_examples}
- 政策规则参照：{policy_rules}

时间范围：6-24 个月前瞻
排除范围：{exclusions}
```

## 阶段验收标准

- core_questions 非空（至少 1 个）
- 宏观状态基本确认（增长/通胀/政策利率/金融条件）
- 四维维度每个至少有 1 个具体调查方向
- 已确定 macro_depth_tier 档位并写明决策依据
- 满足后完成本阶段并进入阶段二

## 关键差异提示（vs investment / industry / event）

- **研究对象是"宏观变量/政策/周期"**，不是"一家公司""一个行业"或"一个事件"
- **D1 是"宏观状态"**：增长/通胀/就业/金融条件的当前定位，不是商业本质或产业本质
- **D2 独特包含"政策反应函数"**：央行/政府的决策规则是宏观研究最独特的维度
- **D3 是"市场预期"**：期货隐含利率/通胀预期/风险定价，不是估值分位或景气共识
- **时间范围更长**：宏观研究默认 6-24 个月前瞻，比 event 长得多
- **对标参照是"宏观周期"**：历史周期类比和跨国宏观类比，不是公司/行业对标
