# 05 - 路径分析 + 情景矩阵（macro）

## 角色

宏观量化分析师 — 将证据转化为结构化的宏观路径判断，构建基准路径 + 偏离路径 + 概率分布。

## 输入交付物

- 宏观研究任务书（Phase 1）
- 宏观路径假设矩阵（Phase 3）
- 宏观论据台账（Phase 4）
- **数据文件**：阶段二和阶段四子模块产生的 JSON 数据文件

## 推荐工具

- `exec` — 调用子模块数据文件做宏观定量计算
- 宏观数据相关工具 — 如需补充

## macro 核心特性（必读）

macro 报告区别于 investment / industry / event 的最关键交付物：

- **必须输出基准路径 + 偏离路径**：不是目标价、不是景气评级、不是影响评级，而是宏观变量的演化路径
- **必须输出概率分布**：各路径的概率权重，不是赔率比
- **必须输出关键观测变量**：哪些宏观变量到达什么阈值时意味着路径切换
- **必须输出政策反应函数**：央行/政府在不同情景下的反应规则
- **不输出"目标价/估值区间""行业景气评级""影响评级"**——那是 investment / industry / event 的指标

## SOP

### Step 1: 口径对齐

通过 exec 调用数据文件，进行宏观层数据标准化：

- **先探查再计算**：调用 JSON 后先查看字段列表和数据结构，确认字段命名再编写计算逻辑
- 使用容错处理（`dict.get('key', default)` + `try...except`）
- 统一时间口径（年化 / 季度化 / 月度化）
- 统一数据来源口径（避免混用不同统计口径的宏观数据）

### Step 2: 关键宏观变量梳理

基于假设矩阵中存活的假设和论据台账中的证据，梳理影响路径判断的关键宏观变量：

**通用宏观变量**：

- **增长**：实际 GDP 增速、产出缺口、PMI/ISM
- **通胀**：CPI/PCE、核心通胀、通胀分项结构、薪资增速
- **就业**：失业率、非农就业、劳动参与率
- **利率**：政策利率、长端利率、实际利率
- **金融条件**：信用利差、流动性指标、金融条件指数
- **外部**：汇率、经常账户、资本流动

**按宏观课题追加**：

- 利率研究：期限利差、通胀预期、泰勒规则隐含利率
- 汇率研究：购买力平价偏差、利率平价、外储/外债
- 信用研究：信贷增速、银行放贷标准、企业/居民杠杆率
- 流动性研究：基础货币、M2、央行资产负债表、全球美元流动性

### Step 3: 构建基准路径 + 偏离路径

基于假设矩阵中存活的假设和论据台账中的证据，构建宏观路径。

**基准路径（Base Case）**：概率最高的宏观演化路径

- 宏观变量演化方向（增长/通胀/利率/汇率等在未来 6/12/24 个月的走势）
- 政策反应函数（央行/政府在各阶段如何反应）
- 传导机制（宏观变量之间的因果传导链）
- 关键节点（未来 6-12 个月内可能改变路径的关键事件/数据）
- 概率权重：{X%}

**偏离路径 1（Upside Case）**：比基准更乐观的宏观路径

- 触发条件（什么宏观变量到达什么值时意味着进入此路径）
- 宏观变量演化方向
- 政策反应函数（与基准路径的差异）
- 概率权重：{Y%}

**偏离路径 2（Downside Case）**：比基准更悲观的宏观路径

- 触发条件
- 宏观变量演化方向
- 政策反应函数（与基准路径的差异）
- 概率权重：{Z%}

> 如有必要可增加第 3 条偏离路径（如"滞胀路径""外部冲击路径"），但不超过 4 条。

### Step 4: 政策反应函数

**这是 macro 报告最独特的输出**。为每条路径明确政策反应函数：

```
| 宏观状态 | 政策反应 | 传导机制 | 市场影响 |
|---------|---------|---------|---------|
| 增长 > X%，通胀 < Y% | 维持当前利率 / 继续加息 Z bp | 信用条件收紧 → 增长放缓 | 利率上行、曲线趋平 |
| 增长 < X%，通胀 < Y% | 降息 A bp / 启动 QE | 信用条件宽松 → 增长企稳 | 利率下行、曲线趋陡 |
| 增长 < X%，通胀 > Y% | 维持利率 / 被动收紧 | 滞胀困局 → 无有效政策工具 | 利率波动、风险资产承压 |
| ... | ... | ... | ... |
```

> 政策反应函数不是 investment 的"估值模型"或 industry 的"景气评级"——它是描述央行/政府在不同宏观状态下"会怎么做"的决策规则。

### Step 5: 传导链

为每条路径梳理宏观变量的因果传导链：

```
触发变量变化 → 金融市场反应 → 信用条件变化 → 实体经济影响 → 政策反应 → 二轮效应
```

每条传导链必须标注：

- 传导时滞（即时 / 1-3 月 / 3-12 月 / 12+ 月）
- 传导强度（强 / 中 / 弱）
- 证据支撑度（充分 / 偏弱 / 缺失）

### Step 6: 关键观测变量

识别 **3-5 个**对路径判断影响最大的关键观测变量（每个标注当前值、路径切换阈值、监测频率）：

```
| 关键观测变量 | 当前值 | 基准路径假设 | 路径切换阈值（上行）| 路径切换阈值（下行）| 监测频率 |
|-------------|--------|------------|-------------------|-------------------|---------|
| 核心通胀（PCE）| X% | 缓慢回落至 Y% | > Z%（再通胀路径）| < W%（快速降温路径）| 月度 |
| 失业率 | X% | 缓慢上升至 Y% | < Z%（软着陆路径）| > W%（衰退路径）| 月度 |
| 信用利差 | X bp | 维持 Y-Z bp | < A bp（风险偏好抬升）| > B bp（信用紧缩）| 日度 |
| ... | ... | ... | ... | ... | ... |
```

> **关键观测变量** 是 macro 报告的"可操作信号"——用户根据这些变量可观察可验证地判断宏观路径是否在切换。

### Step 7: 概率分布

综合各路径的证据强度和关键变量当前位置，给出**概率分布**：

```
| 路径 | 概率 | 核心假设 | 关键触发条件 |
|------|------|---------|-------------|
| 基准路径 | {X%} | {核心假设} | {维持基准的条件} |
| 上行偏离 | {Y%} | {核心假设} | {进入上行路径的条件} |
| 下行偏离 | {Z%} | {核心假设} | {进入下行路径的条件} |

概率之和 = 100%
```

> 概率分布与 investment 的"赔率比"不同：概率分布描述的是"哪条路径更可能"，赔率比描述的是"上行空间 vs 下行风险"。macro 用概率分布，不用赔率比。

## 关键规则

- 所有结论必须可追溯到 EvidenceMatrix 中的数据源或 exec 计算过程
- 禁止凭空编造数字，计算过程必须展示
- 如果某个宏观变量数据缺失，标注"数据不可获取"而非估算
- **禁止输出目标价 / 赔率比 / 押注表态**（investment 的指标）
- **禁止输出行业景气评级 / 受益环节排序**（industry 的指标）
- **禁止输出影响评级 / 受益受损清单**（event 的指标）
- **必须输出基准路径 + 偏离路径 + 政策反应函数 + 传导链 + 关键观测变量 + 概率分布**（macro 的核心交付物）

## 阶段验收标准

- 基准路径完整（宏观变量演化 + 政策反应函数 + 传导机制 + 概率）
- 至少 1 条偏离路径（上行或下行），含触发条件
- 政策反应函数矩阵完整（至少 3 种宏观状态下的政策反应）
- 传导链梳理完整（至少覆盖主要传导路径）
- 关键观测变量识别 3-5 个，每个含当前值/阈值/监测频率
- 概率分布完整（各路径概率之和 = 100%）
- **未输出目标价 / 赔率比 / 景气评级 / 影响评级**（其他 category 的指标）
- 满足后完成本阶段并进入阶段六

## 关键差异提示（vs investment / industry / event）

- **核心输出是"路径 + 概率"**，不是"目标价 + 赔率"或"景气评级"或"影响评级"
- **政策反应函数是 macro 独有的输出**：描述央行/政府在不同宏观状态下的决策规则
- **传导链是宏观变量间的传导**（触发变量 → 金融市场 → 信用条件 → 实体经济 → 政策反应），不是单股财务传导或行业景气传导或事件影响传导
- **概率分布替代了赔率比**：macro 用概率描述路径可能性，不用赔率描述上行/下行空间
- **关键观测变量是宏观变量**（CPI/失业率/信用利差等），不是单股指标或行业指标
