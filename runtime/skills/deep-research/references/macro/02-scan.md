# 02 - 信息扫描（macro · 多模块并行 subagent）

## 角色

信息扫描负责人 — 按 macro 四维维度分派子模块采集宏观数据，只记录不判断。

## 输入交付物

宏观研究任务书（来自 Phase 1）

## 执行模式

**多模块并行** — 按维度启动独立子模块，每个子模块负责一个维度的数据采集。

## SOP

### Step 1: 构造子模块任务

读取宏观研究任务书中的四维分析维度、对标参照、深度档位，为每个维度构造子模块任务描述。

### Step 2: 启动子模块

为以下维度各启动一个子模块（**注意每个子模块都是宏观视角，不是单股/行业/事件**）：

---

**子模块一（宏观状态扫描）**：

```
你是信息扫描专家，负责采集 {macro_subject} 的当前宏观状态数据。
调查方向：{4d_dimensions.D1}

采集内容：
- 增长数据（实际 GDP 增速/趋势、PMI/ISM、工业产出、零售销售）
- 通胀数据（CPI/PCE/核心通胀、PPI、通胀分项结构、薪资增速）
- 劳动力市场（失业率、非农就业、劳动参与率、职位空缺/求职比）
- 金融条件（实际利率、信用利差、流动性指标、金融条件指数）
- 外部平衡（经常账户、资本流动、汇率、外债/外储）

要求：广撒网采集，只记录数据不做分析判断。每个调查方向至少一次工具调用。
禁止：不得再 spawn 子 agent，所有工具调用必须由你自己直接执行。
输出：按调查方向分组的数据摘要，含数据时间戳和来源。
```

---

**子模块二（边际变化与政策反应函数扫描）**：

```
你是信息扫描专家，负责采集 {macro_subject} 的边际变化和政策反应函数数据。
调查方向：{4d_dimensions.D2}

采集内容：
- 最新数据相对预期的偏差（过去 3 个月主要数据超预期/低于预期情况）
- 趋势加速/减速/拐点信号
- 央行最新政策声明/会议纪要/前瞻指引
- 央行官员近期讲话/表态/投票记录
- 财政政策最新动态（预算/税收/支出计划）
- 政策规则参照（泰勒规则隐含利率、财政规则空间）
- 政策传导机制数据（信贷增速/银行放贷标准/企业融资成本）

要求：聚焦"变化"和"政策反应规则"，记录事实不做判断。所有事件标注时间戳。
禁止：不得再 spawn 子 agent。
输出：按时间线（最近 → 较远）排列的关键变化和政策信号。
```

---

**子模块三（市场预期扫描）**：

```
你是信息扫描专家，负责采集 {macro_subject} 的市场预期和定价数据。
调查方向：{4d_dimensions.D3}

采集内容：
- 利率预期（期货/远期市场隐含的政策路径、OIS 定价）
- 通胀预期（盈亏平衡通胀率、通胀互换、调查预期）
- 增长预期（卖方一致预期、PMI 预期、消费者信心）
- 风险定价（VIX、信用利差、期限利差、新兴市场利差）
- 仓位与情绪（CFTC 持仓、基金经理调查、ETF 资金流向）
- 跨市场定价（股/债/汇/商品的相关性和隐含预期）

要求：客观记录市场预期数据，不做自己的判断。
禁止：不得再 spawn 子 agent。
输出：市场预期方向总结 + 关键数据点 + 预期偏差清单。
```

---

**子模块四（宏观历史与跨国对标扫描）**：

> 给后续报告的"路径分析""政策反应函数""历史框架"章节提供原料。按 ResearchScope 中的 `macro_depth_tier` 档位执行。

```
你是宏观研究专家，负责为 {macro_subject} 采集"历史周期与跨国对标"维度的研究原料。
执行档位：{macro_depth_tier}（来自 ResearchScope）

按档位采集：

| 档位 | 采集内容 | 输出下限 |
|------|---------|---------|
| full | 【1】2-3 个本国历史上类似宏观周期完整复盘（每个 ≥600 字，含宏观状态、政策反应、市场表现、后续演化）<br>【2】1-2 个跨国宏观类比（其他经济体类似宏观状态的处理方式和结果，每个 ≥500 字）<br>【3】3-5 个宏观范式案例（每个 ≥200 字），来自 paradigms.md（再通胀/衰退/滞胀/流动性宽松/紧缩/风险偏好抬升/收缩等）| 2500 字 |
| lite | 【1】1-2 个本国类似宏观周期简述（每个 ≥300 字）<br>【2】1 个跨国宏观类比简述（≥300 字）<br>【3】1-2 个宏观范式案例（每个 ≥150 字）| 1000 字 |

通用要求：
- 引用具体时间、数据、政策决策，禁止"历史上类似时期表明..."这种空话
- 跨国类比要找"宏观状态 + 政策约束相似"的时期，不是简单"同国家"
- 原料确实不存在时必须显式声明缺失原因，禁止编造
- 数据可来自央行数据库、BIS、IMF、世界银行、彭博等

禁止：不得再 spawn 子 agent。
输出：按【1】【2】【3】分组，开头标注本次实际执行档位。
```

### Step 3: 汇总 ScanFindings

收齐所有子模块的提交结果后，将各维度数据摘要汇总为信息采集底稿。不做分析，只做结构化整理。

## 数据文件传递

子模块内工具调用产生的数据文件由系统自动持久化。子模块向主模块汇报时，系统自动汇总数据文件路径、字段结构和 exec 调用模板。后续阶段五可直接通过 exec 调用这些文件做定量计算。

## 产出交付物：宏观信息采集底稿

```
## D1 宏观状态
{子模块一的数据摘要}

## D2 边际变化与政策反应函数
{子模块二的数据摘要 — 按时间线排列}

## D3 市场预期
{子模块三的数据摘要 — 含预期偏差清单}

## 历史周期与跨国对标
执行档位：{full | lite}
{按档位输出对应内容}

## 数据文件引用
{系统自动拼接的数据文件路径列表}
```

## 阶段验收标准

- 子模块一、子模块二、子模块三已提交结果（必选）
- D1 宏观状态核心数据已确认（增长/通胀/政策利率/金融条件）
- D2 政策反应函数关键信号已采集（央行声明/官员讲话/政策规则）
- D3 市场预期核心定价已采集（利率预期/通胀预期/风险定价）
- 历史周期模块按档位达标：
  - tier=full：三件事均有实质输出，总字数 ≥ 2500 字
  - tier=lite：两件事均有实质输出，总字数 ≥ 1000 字
- 满足后完成本阶段并进入阶段三

## 关键差异提示（vs investment / industry / event）

- **子模块聚焦宏观变量**：不采集单股财报/行业CR5/事件细节，聚焦GDP/通胀/利率/汇率/政策
- **D2 子模块最关键**：政策反应函数是宏观研究最独特的维度，采集深度决定路径分析质量
- **D3 子模块采集"期货隐含预期"**：不是估值分位或景气共识，而是市场对未来政策路径的定价
- **历史类比聚焦"宏观周期"**：类似宏观状态下的政策反应和市场演化，不是公司/行业/事件类比
