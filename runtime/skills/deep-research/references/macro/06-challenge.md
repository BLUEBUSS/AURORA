# 06 - 多空辩证 + Pre-mortem（macro）

## 角色

空方 / 辩证方 — 对宏观路径判断进行反向审视与辩证检验，防止确认偏误和政策假设偏差。

**审查立场**：你的职责是找出问题，不是确认正确。对每个假设的放行，必须给出显式的放行理由（"为什么这个假设的证据足够可信"），而非默认通过。没有显式论证的放行等同于未审查。

## 输入交付物

- 宏观路径情景矩阵（Phase 5）
- 宏观论据台账（Phase 4）
- 宏观路径假设矩阵（Phase 3）

## 推荐工具

- `open_search` — 补充检索验证特定宏观数据
- `exec` — 反向计算验证宏观变量推演是否自洽

## SOP

### Step 1: 信源审查

逐一检查每个假设的证据质量：

- 是否有假设仅依赖**单一信源**？（如只有 1 个央行官员讲话支撑某政策路径）
- 数据是否**过时**？（宏观数据通常按月/季更新，超过 3 个月需标注）
- 是否存在**循环引用**？（A 引用 B，B 引用 A）
- 是否有**模型依赖**？（某个路径假设全部基于某个宏观模型的推演，缺乏现实数据支撑）

如果发现单一信源依赖或模型依赖，尝试用 `open_search` 补充验证。

### Step 2: 路径自洽性审查

审视路径情景矩阵中的关键假设：

- **基准路径的宏观变量演化是否自洽？**（如：增长上行但通胀下行——需要解释为什么，如供给侧改善）
- **偏离路径的触发条件是否明确？**（如：什么 CPI 读数触发再通胀路径？什么失业率触发衰退路径？）
- **政策反应函数是否合理？**（央行在给定宏观状态下真的会这样反应吗？有历史先例吗？）
- **概率分布是否合理？**（基准路径概率是否过高/过低？偏离路径是否被低估？）

通过 exec 做反向验证：如果基准路径成立，隐含的宏观变量值是否与历史类似阶段一致？

### Step 3: 政策假设审查

**macro 特有审查**：央行/政府的政策反应是宏观研究最大的不确定性来源。

- **央行真的会按"规则"反应吗？**（泰勒规则 vs 实际决策的偏差历史）
- **政策约束是否被充分考虑？**（财政空间、政治约束、外部约束如汇率稳定 vs 货币独立）
- **政策时滞是否被合理估计？**（从数据恶化到政策反应通常有 2-6 个月时滞）
- **非常规政策工具是否被考虑？**（QE/QT、前瞻指引、收益率曲线控制等）

如果发现政策假设有明显偏差，列入 Critical 或 Minor 缺陷。

### Step 4: 遗漏检查

检查是否遗漏了重大宏观风险维度：

- **尾部风险**：低概率高产出的宏观冲击（地缘政治、能源危机、金融危机）
- **非线性效应**：某个宏观变量突破阈值后的非线性反应（如通胀预期脱锚、信用市场冻结）
- **跨境传导**：其他经济体的宏观变化对本国的传导
- **政策错误**：央行/政府犯错的可能性（过度紧缩/过度宽松）
- **结构性变化**：宏观结构是否正在发生不可逆变化（人口、技术、全球化退潮）

### Step 5: Pre-mortem 推演

**假设 12 个月后，我们的宏观路径判断被证明是大错特错的。最可能是因为什么？**

必须给出**至少 2 个致命风险点**，每个包含：

- 具体的触发场景描述（宏观层）
- 触发概率评估（高 / 中 / 低）
- 如果触发，对路径判断的影响程度
- 当前分析中是否已充分考虑

**macro 特有的 Pre-mortem 角度**：

- 政策反应函数错误：央行比预期更鹰/更鸽，反应函数假设被证伪
- 通胀/增长结构误判：通胀的持续性或增长的韧性被低估/高估
- 外部冲击未被定价：地缘政治/能源/金融风险改变宏观均衡
- 历史类比失效：当前宏观组合与历史相似阶段的关键差异被忽视

### Step 6: 非共识交叉验证

将 D1/D2 的事实（宏观状态 + 政策反应函数）与 D3 的市场预期进行最终比对：

- 非共识假设是否经得起证据检验？
- 是否出现了"市场定价软着陆但宏观数据指向衰退"或"市场定价衰退但政策反应函数指向软着陆"的情况？
- 认知差的"验证窗口"是否足够（宏观数据通常需要 2-6 个月验证，不像 event 的天/周级别）

### Step 6.5: 历史一致性审查（按 macro_depth_tier 档位适配）

**tier = full 时执行**：调取 02-scan 阶段"历史周期与跨国对标"子模块的产出，对当前路径假设做反向检验。

**审查维度**：

1. **本国周期一致性**：当前宏观状态（增长/通胀/利率/就业组合）与历史上"最像"的周期的同位特征是否匹配？
   - 检查至少 3 个同位特征指标（如产出缺口、通胀趋势、政策利率水平、期限利差）
   - 如果不匹配，需解释——可能是结构性变化，也可能是周期判断错误

2. **跨国类比一致性**：当前结论与其他经济体类似宏观阶段的政策反应和后续演化是否一致？
   - 如果一致：用跨国案例补充支撑该路径的概率
   - 如果不一致：必须给出"本国特殊性"的具体理由

3. **宏观范式一致性**：报告隐含的"宏观范式标签"（再通胀/衰退/滞胀/软着陆等）是否与该范式的历史案例特征吻合？
   - 例：贴"软着陆"标签 → 检查 paradigms.md 中该范式的"识别信号"（通胀回落但增长维持正增长、失业率温和上升、政策转向适时）是否在当前宏观状态中观察到
   - 例：贴"滞胀"标签 → 检查"通胀持续上行 + 增长持续下行"信号是否同时满足

**tier = lite 时**：简要参照，不做系统性审查。

**判定升级**：如果发现历史一致性出现重大冲突，列入 Critical 缺陷，回退到 Phase 4 补证。

### Step 7: 质控判定

根据以上审查结果做出质控判定：

**Critical 缺陷**（必须回退补充）：

- 某路径假设的核心证据完全缺失或仅有模型推演支撑
- 关键宏观变量数据无法追溯到数据源
- 路径情景矩阵的宏观变量演化存在逻辑不自洽
- 政策反应函数假设与历史先例严重矛盾且无合理解释
- 历史一致性出现重大冲突且无合理解释（full 档位）

→ 明确指出缺陷，通过阶段更新追加"补充证据"阶段，回退到阶段四为缺陷假设启动子模块补充采集。

**充分搜索出口**（避免无效重复回退）：

- 若 Phase 4 论据台账中已展示该证据的"≥ 3 条具体检索路径"且明确标注"经充分搜索后未找到"，则该证据缺失**不再列为 Critical**，转为 Minor 放行
- 在 ChallengeVerdict 中标注"该项证据已充分搜索仍缺失"，并要求 Phase 7 报告在"数据局限性声明"中显式说明

**Minor 瑕疵**（标注但放行）：

- 某宏观变量数据不够新（但不影响核心路径判断）
- 政策时滞估计不够精确
- 跨国类比的某个细节缺失但不影响范式判断

→ 标注在 ChallengeVerdict 的 issues 中，放行进入 Phase 7。

**通过**：
→ 无 Critical 缺陷，进入 Phase 7。

## 迭代控制

- 本阶段最多触发 **2 次回退**到 Phase 4
- 超过上限，强制放行进入 Phase 7，在 ChallengeVerdict 中标注未解决的缺陷
- 每次回退必须明确：哪个假设有缺陷、需要补充什么具体证据

## 阶段验收标准

- 完成信源审查、路径自洽性审查、政策假设审查、遗漏检查、Pre-mortem、非共识比对、历史一致性审查、政策反应函数复核
- 做出明确判定（通过 或 返工）
- 如果通过：完成本阶段并进入阶段七
- 如果返工：追加补充研究阶段，回退到阶段四

## 关键差异提示（vs investment / industry / event）

- **路径自洽性审查**替代了 investment 的"参数压测"和 industry 的"景气评级审查"——核心是验证宏观变量演化是否逻辑自洽
- **政策假设审查是 macro 独有的**：央行/政府的政策反应是最大的不确定性来源
- **Pre-mortem 角度不同**：聚焦"政策反应函数错误""通胀/增长结构误判""外部冲击未被定价"
- **历史一致性审查聚焦"宏观周期"**：类似宏观状态下的政策反应和市场演化，不是公司/行业/事件类比
