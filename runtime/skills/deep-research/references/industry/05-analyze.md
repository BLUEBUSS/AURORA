# 05 - 量化分析 + 情景矩阵（industry）

## 角色

行业量化分析师 — 将证据转化为可比较的行业层定量结论，构建 **高景气 / 中性 / 承压** 三情景矩阵 + 受益环节排序。

## 输入交付物

- 行业研究任务书（Phase 1）
- 行业格局假设矩阵（Phase 3）
- 行业论据台账（Phase 4）
- **数据文件**：阶段二和阶段四子模块产生的 JSON 数据文件

## 推荐工具

- `exec` — 调用子模块数据文件做行业层定量计算（核心工具）
- 估值/景气相关数据工具 — 如需补充

## 与 investment 的核心差异（必读）

- **不输出目标价/估值区间**：行业不能直接交易，目标价无意义
- **不输出赔率比/加权目标空间百分比**：相同原因
- **不输出"押注表态"**：industry 用"行业景气评级"代替（高景气 / 中性 / 承压）
- **必须输出"关键监测变量 + 阈值"**：明确未来观察哪几个变量、各变量到达什么值时观点切换
- **必须输出"受益环节排序"**：产业链各环节按景气改善幅度排序，给出 top 3 受益环节

## SOP

### Step 1: 口径对齐

通过 exec 调用数据文件，进行行业层数据标准化：

- **先探查再计算**：调用 JSON 后先查看字段列表和数据结构，确认字段命名再编写计算逻辑
- 使用容错处理（`dict.get('key', default)` + `try...except`）
- 统一统计口径（GICS / 申万 / 中信，确保跨数据源一致）
- 统一时间口径（年化/季度化）
- 统一可比基准（行业平均 / 行业中位 / 龙头集合）

数据文件调用示例：

```python
import json
with open("{提交结果中的文件路径}", "r") as f:
    data = json.load(f)

# 行业层指标计算示例：CR5
top5_revenue = sum(sorted([c['revenue'] for c in data['companies']], reverse=True)[:5])
total_revenue = data['industry_total_revenue']
cr5 = top5_revenue / total_revenue
```

### Step 2: 关键行业指标计算

计算以下行业层指标（按行业类型选择适用的）：

**通用行业指标**：

- **规模与增长**：行业总规模（亿元）、近 5 年 CAGR、最新季度同比
- **集中度**：CR3 / CR5 / CR10 / HHI 指数及其历史变化
- **盈利能力**：行业平均毛利率、行业 ROE 中位、龙头与中位的差距
- **资本效率**：行业资本开支强度（capex/revenue）、产能利用率
- **库存周期位置**：行业平均存货周转天数、PPI、PMI
- **估值水平**：行业平均 PE/PB 历史 10 年分位、行业溢价系数

**制造业 / 周期类追加**：

- 在建工程占固定资产比例
- 龙头资本开支同比
- 产能利用率
- 价格 / 成本剪刀差

**消费品类追加**：

- 渠道库存
- 终端动销同比
- 龙头出厂价
- 单店收入（同店增长）

**TMT / 成长类追加**：

- 渗透率 / 市场普及率
- 新增用户数 / DAU
- 单位经济模型（LTV / CAC）
- 龙头研发投入强度

**周期 / 资源类追加**：

- 大宗商品价格曲线
- 全球供需平衡表
- 库存周期位置
- 替代品竞争

### Step 3: 构建 高景气 / 中性 / 承压 三情景矩阵

基于假设矩阵中存活的假设和论据台账中的证据，构建三种行业层情景。

**每个情景必须显式声明对应的宏观假设**——禁止只用行业层变量，否则到 Phase 7 写情景章节时无法满足"宏观假设显式声明"的要求。

**高景气情景**：最乐观的假设组合成立

- 行业层假设参数（取乐观值）：行业增速、CR5 变化、行业 ROE 中位、产能利用率
- **宏观假设**（必填）：信用周期阶段 / 利率区间 / 行业相关大宗商品价格 / 产业政策方向
- 对应的关键变量预测值（覆盖未来 1 / 3 / 5 年）
- 触发条件：什么信号出现意味着进入此情景

**中性情景**：最可能的情景

- 行业层假设参数（取中性值，基于当前趋势外推）
- **宏观假设**（必填）
- 对应的关键变量预测值
- 触发条件

**承压情景**：最悲观的假设组合成立

- 行业层假设参数（取悲观值）
- **宏观假设**（必填）
- 对应的关键变量预测值
- 触发条件

### Step 4: 关键监测变量识别

识别 **3-5 个**对景气评级影响最大的关键变量（每个标注当前值、阈值、阈值含义）：

```
| 关键变量 | 当前值 | 高景气阈值 | 承压阈值 | 监测频率 |
|---------|--------|-----------|----------|---------|
| 行业 CR5 | X% | > Y%（向上）| < Z%（向下）| 季度 |
| 上游原材料价格 | X 元/吨 | < Y（成本下行）| > Z（成本上行）| 月度 |
| 龙头资本开支同比 | X% | < -Y%（供给收缩）| > +Z%（供给过剩）| 季度 |
| 政策周期位置 | 扶持/规范/收紧 | 扶持上行 | 收紧 | 事件驱动 |
| ... | ... | ... | ... | ... |
```

> **关键变量 + 阈值** 是 industry 报告的"押注信号"，等同于 investment 的"目标空间"——用户根据这些变量可观察可验证地判断行情。

### Step 5: 敏感性分析

识别对结论影响最大的 2-3 个关键变量：

- 每个变量变动 ±10% / ±20% 时，行业层结论如何变化（增速预测、CR5 变化、ROE 中位）
- 标注哪个变量是"胜负手"（对结论的翻转最敏感）

### Step 6: 受益环节排序

**这是 industry 报告区别于 investment 报告最重要的输出**。

按景气改善幅度从大到小排序产业链各环节，给出 **top 3 受益环节**：

```
| 排名 | 环节 | 排序逻辑 | 代表玩家 | 关键变量传导 |
|-----|------|---------|---------|-------------|
| 1 | 上游 X | 量价齐升，议价权强 | A、B 公司 | 通过 X 变量改善而受益 |
| 2 | 中游 Y | 量增价稳，份额向龙头集中 | C、D 公司 | 通过 Y 变量改善而受益 |
| 3 | 下游 Z | 需求结构优化但价格压力 | E、F 公司 | 通过 Z 变量改善而受益 |
```

> 不输出"目标价"，但要给出**该环节代表玩家**清单，供后续 investment 类研究跟进。

### Step 7: 行业景气评级

综合三情景概率权重 + 关键变量当前位置 + 受益环节质量，给出**行业景气评级**：

| 评级       | 含义                                                           | 触发条件                            |
| ---------- | -------------------------------------------------------------- | ----------------------------------- |
| **高景气** | 中性 + 高景气情景概率合计 ≥ 70%；且关键变量多数处于改善位置    | 至少 3 个关键变量处于"高景气阈值"侧 |
| **中性**   | 三情景概率分布相对均衡（最大情景 ≤ 50%）；关键变量有改善有恶化 | 关键变量呈分化态势                  |
| **承压**   | 中性 + 承压情景概率合计 ≥ 70%；且关键变量多数处于恶化位置      | 至少 3 个关键变量处于"承压阈值"侧   |

> 评级与 investment 的押注表态本质不同：押注表态对应"买卖动作"，景气评级对应"行业方向研判"。industry 报告不应转译为买卖建议，由读者结合 investment 类研究做单股决策。

## 关键规则

- 所有数字必须可追溯到 EvidenceMatrix 中的数据源或 exec 计算过程
- 禁止凭空编造数字，计算过程必须展示
- 如果某个指标数据缺失，标注"数据不可获取"而非估算
- **禁止输出目标价 / 加权目标空间 / 赔率比**（这些是 investment 的指标，industry 不适用）
- **必须输出关键监测变量 + 受益环节排序 + 行业景气评级**（这是 industry 的核心交付物）

## 阶段验收标准

- 三情景矩阵完整（高景气/中性/承压均有行业层假设、**宏观假设**、关键变量预测、概率权重、触发条件）
- 关键监测变量识别 3-5 个，每个含当前值/阈值/监测频率

- 受益环节排序给出 top 3，每个含排序逻辑、代表玩家、关键变量传导
- **行业景气评级已给出**（高景气/中性/承压），评级依据可追溯
- **未输出目标价 / 赔率比 / 押注表态**（这些是 investment 指标，industry 不适用）
- 满足后完成本阶段并进入阶段六
