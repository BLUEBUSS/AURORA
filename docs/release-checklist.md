## Alpha 已知限制（不冒充正式产品）

完整文件/报告管理、自选、提醒调度、复杂图表、多媒体、PDF/Word、批注、分享和正式安装升级工具未完成。项目分组/置顶为浏览器元数据。现有数据工具覆盖与真实供应商权限须逐项验证；没有美股实时行情、个股期权或清算热力图的完整验收承诺。

Kimi 模型、联网检索及引用已真实在线验证；其他数据供应商仍待用户自己的凭据。CI 与大部分自动测试使用合成服务，不消耗真实额度。Linux CI 通过也不等于所有操作系统已人工完整验收。

## 公开前最终复核

核对目标提交、仓库可见性、许可证、README 和 CI；确认未包含运行状态、Key、研究文件、私人日志/截图。仅在取得转公开指令后修改可见性。若另行分发安装包或构建附件，对实际附件重新扫描并验证，不把 Git 源码检查结果代替二进制检查。
