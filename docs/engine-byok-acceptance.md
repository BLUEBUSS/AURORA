## 实施内容

- 独立 Node 入口同源提供生产前端、受保护的 HTTP 与协议3 WebSocket；不转发旧 HTTP 调试认证入口，不依赖旧构建与状态目录。
- 使用原系统采用的 Pi Agent 执行核心，迁入 task-store、task_create、task_update、任务导航及35份研究方法文件。原全局事件桥改为 AsyncLocalStorage，隔离并行研究上下文。
- 兼容层处理会话、模型绑定、幂等提交、流式事件、停止、子任务、来源和磁盘存储。保存问题后才发送 ACK；不保留标签页记录也能从后端接管运行。错误和停止状态跨刷新保留。
- 子任务使用同一用户配置，最多并行三个，不能继续派发；主研究有并发、调用轮数和时间限制。子任务记录落盘，不作为普通聊天污染侧栏。
- 金融工具来自公开独立包 financial-agent-tools 的 `6ec79fd0616ac755df7a0b54d0a026b074c2a477`，保留 LICENSE、NOTICE、哈希清单及原工具测试。未继承作者数据凭据。
- Markdown 报告唯一命名写入工作区，右栏展示并可在中间阅读；刷新后仍可打开。来源摘要与记录按会话校验归属。
- 模型设置提供协议、Base URL、模型 ID、用户 Key、上下文/输出限制和可选 SEC 联系标识。明确点击后测试再保存，错误不回显 provider 的原始鉴权内容。
- Windows Key 使用当前用户 DPAPI，其他平台使用受限文件；浏览器不保存 Key。修改/移除模型与启动研究互斥。
- 会话名称、归档及恢复跨刷新和服务重启保留。

## 已执行的验收

1. 本地 OpenAI 兼容 SSE 服务驱动真实 Pi 循环：task_create → read → sessions_spawn → task_update → write_report → 最终回答。不是 mock WebSocket 直接塞入最终文本。
2. 无模型时阻止研究；错误 Key 不保存且不回显；保存/移除、Windows 不落明文 Key、所有主/子调用仅使用测试用户提供的 Key。
3. 提交幂等、会话归属、停止流式响应、运行中禁止改模型；名称/归档/历史跨重启保留，重启不自动调用模型。
4. 浏览器从空配置完成模型设置、发送、工具/子任务、报告打开和刷新；清空 sessionStorage 后仍能接管运行并停止，再刷新保持停止状态。
5. 在原项目之外复制候选源码，以冻结锁文件安装并构建，依赖解析来自该目录自己的 node_modules。其编译产物同样完成模型配置、五种工具调用和历史读回。

## 差异和剩余边界

- 复用执行核心、任务逻辑和工具，不迁入整套多渠道 OpenClaw Gateway；任意 shell、完整自动压缩及所有旧 hooks 未纳入。
- 协议由 Pi SDK 提供，本轮端到端模型协议覆盖 Chat Completions；其他真实服务仍待验收。
- 当前模型调用为连接测试、主研究和子任务，都使用用户配置。旧的独立意图/摘要/来源定位辅助模型没有另外迁入，也不会回落旧供应商。
- SEC 公告/财务可由用户联系标识启用；付费现货美股行情、宏观数据和搜索没有配置入口。加密与币安公开端点仅标为已注册、未在线验证。
- 完整文件管理、自选、提醒、图表/PDF/Word 等仍属阶段 D，整个首版尚未完成。
- 旧 PowerShell 脚本仍是开发兼容入口，独立发行走 pnpm build / pnpm start。安装器、GitHub 云端 CI、根许可证和公开发布仍待阶段 E。
