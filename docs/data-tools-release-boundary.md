# 数据工具与凭据发布边界

当前决策：公开 AURORA 前后端、Agent 编排、工具定义及数据供应商适配实现。需要认证的接口由每个用户自行申请并配置自己的 Key；无需认证的公开接口可直接使用。不再要求拆分私有插件或托管数据服务。

## 可公开与不得分发的内容

- 可公开：工具参数、调用逻辑、数据规范化、来源引用、能力说明、测试夹具、空白配置模板和申请文档。保留第三方来源和许可证，根许可证已选择 MIT，正式公开仍待确认。
- 不分发：作者或其他用户的 Key、固定私人账号标识、模型/数据源运行配置、研究历史、缓存、日志和私人截图。安装包必须以空白用户状态启动，不能复制开发者状态目录。
- 没有用户凭据的接口返回未配置；不能用作者的 Key、旧配置或隐藏代理兜底。供应商网络限制、权限和额度独立于代码是否开源。
- 密钥只交给用户本机后端和选定的对应供应商；不进入模型提示词、浏览器持久化、源码、打包产物或日志。不向不匹配的供应商转发同一个 Key。
- 发布前扫描候选文件、Git 历史和实际打包产物。忽略规则和文件名检测只能提供部分保护，不能替代完整凭据检查。

## 当前实现

模型凭据由本机后端保存：Windows 使用当前用户 DPAPI；其他平台使用受限权限文件。模型 API 的读取响应不返回 Key。官方 Kimi 搜索使用用户当前配置的同一官方服务 Key，不继承原专用搜索服务身份。

金融工具构造时传入明确配置，而不是自动读取整个开发者环境。已将 SEC、EODHD、Alpha Vantage、FRED 的用户配置接入设置页，并在每轮研究开始时只注入已启用的凭据。付费加密增强源设置仍待后续接入。配置入口已实现不代表用户账户或全部供应商端点已在线验证。

2026-09-27 早先“保留数据工具私有”的决定已被本决策替代。发布检查器允许数据工具源码，但继续拒绝个人配置、常见凭据文件、生成物和可识别的秘密。解除源码分类拦截不代表已授权推送或已完成发行验收。

配置中心的实施范围及当前能力清单见 [数据源配置计划](data-source-configuration.md)。
