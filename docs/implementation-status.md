# 当前交付状态

截至 2026-09-27，AURORA 是独立本机运行的 Alpha 源码应用，采用用户自带模型与数据源凭据。研究服务、HTTP/WS 和前端不需要相邻 ANLYST 目录。

## 已实现

- 模型配置、独立 Agent 研究、流式输出、任务与子任务、停止、历史恢复。
- 附件读取、Markdown 报告、引用来源和本机文件边界。
- SEC、EODHD、Alpha Vantage、FRED 配置中心；保存、探测、启停、移除、恢复和工具注入。
- Kimi 实际模型与联网搜索验证。其他数据源需用户自行配置并在线验收。
- 日夜主题、拖动三栏、公司标识、手机基本适配。
