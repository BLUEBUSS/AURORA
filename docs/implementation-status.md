## 实施决定

- 独立项目和 Git 仓库：AURORA；开发分支 `codex/aurora-frontend`。原 ANLYST 的 main、工作树、启动器与研究数据保持不动。
- React 18 / TypeScript / Vite / Zustand；语义 CSS token；Lucide；React Markdown。无指向旧仓库源码、node_modules 或 dist 的构建依赖。
- 第一阶段交付六页本地可交互原型，真实连接适配层以协议夹具验证。后端没有运行，因此不宣称已完成真实账号和模型联调。
- 停止与发送共用一个圆形控制：运行时内部显示方块，终态恢复箭头。按钮始终 `type=button`，防止停止同步更新后同一次点击触发发送。Enter 在运行时只阻止提交；草稿由用户手动发送。
- 开始研究时展开桌面资料栏；完成后资料/生成文件优先，过程折叠。用户重新展开后，普通文本更新不会再次折叠。
- 演示数据与 live 数据分开；token 仅在 transport 内存中。示例来源标为官方资料入口，没有伪装成检索结果。
